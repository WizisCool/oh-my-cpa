# Oh My CPA v0.2.3

## Request diagnostics

- Failed request records show the HTTP status and the upstream's error body when CPA
  supplies them. The list's failure tooltip reads the body from the single-record
  endpoint, keeping that diagnostic content out of the list query and response.
- The request drawer's Diagnostics tab starts with the failure reason, followed by
  the upstream response header snapshot, correlated credential errors, network
  details and the raw request log. Headers are grouped by purpose: request
  identifiers, quota and rate limits, routing and edge, and other diagnostic
  headers. The snapshot can be copied without interpreting provider-specific values.
- Failure bodies are redacted and bounded before storage. Response header snapshots
  drop transport headers and names that can carry credentials or sessions; retained
  values are redacted and bounded. Headers are captured for successful and failed
  requests alike and exposed only in the single-record view.
- When CPA has no request-log file, confirming a download closes the confirmation
  and explains that the file is unavailable instead of reporting a generic failure.

## Upgrade notes

- Back up the persistent SQLite database and preserve its master key before upgrading;
  follow `docs/ops/sqlite-operations.md`. Migrations 037 and 038 add failure status,
  failure body and response header storage to request records. They run automatically
  during startup. Request-record retention defaults are unchanged.
- Older records and records from CPA builds that do not supply these fields cannot
  be backfilled. A failed record with no captured failure detail continues to show
  its failed state without inventing a status or body; missing headers remain absent.
- Captured diagnostics are stored with their request record and expire with it.
  Header snapshots increase storage per record; monitor database growth under the
  configured request-record retention policy.
- This release changes no environment variable or key scope. Compose continues to
  default to `latest`. To pin this release after publication, use
  `wiziscool/oh-my-cpa:v0.2.3` or `wiziscool/oh-my-cpa:0.2.3`.
