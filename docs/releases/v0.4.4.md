# Oh My CPA v0.4.4

Oh My CPA v0.4.4 lets operators price retained unpriced requests at current catalog prices, reworks and renames the price book to Model Pricing, speeds up long-range request record facets, refines console button surfaces and base typography, and keeps landing-page release links current via the site Worker.

## Model Pricing & retroactive pricing for unpriced requests

- **One-time pricing for retained unpriced requests.** Migration `065_usage_price_unpriced.sql` updates `usage_cost_no_reprice` so rows recorded as `unpriced` with no cost can be priced once at the current model and service-tier price (`PriceUnpricedUsage`), while keeping every other locked pricing field immutable. Newly priced amounts fold back into `usage_facts_*` rollup tables in the same transaction so Dashboard and Insights totals match request records.
- **Model and bulk pricing endpoints.** Added `POST /api/v1/pricing/models/{model}/price-unpriced` and `POST /api/v1/pricing/price-unpriced`, each guarded by fail-closed audit logging (`attempt` followed by `success` or `failure`) and documented in `docs/openapi/swagger.json`.
- **Reworked Model Pricing workspace.** Renamed the Price Book page to **Model Pricing** across all four locales, landing navigation, READMEs, and `docs/features/display.md`. Added dynamic filters for unpriced models and models with unbilled requests, channel filter provider marks, single-model and two-step **Price all** confirmation flows, inline suggested-match adoption/dismissal, scope-locked channel override editing, and pager placement under `ResponsiveList` cards.

## Request records performance & console UI polish

- **Faster long-range request record facets and smaller page sizes.** Replaced eleven materialized facet groupings in `usage_events` with a single narrow streaming scan, started loading the bounded request page before full-window facets with `AbortSignal` cancellation on filter or range changes, and added 25- and 50-record page size options alongside 100/250/500.
- **Tactile ink primary controls.** Updated `derivePalette` so primary surfaces default to each palette's ink (`fg` fill, `bg` label) with a subtle lip highlight and drop shadow (`--primary-sheen`, `--shadow-primary`), reserving the palette accent for links, focus rings, and selections while keeping custom theme `overrides.primary` support.
- **Consistent 13px console base typography.** Declared `body { font-size: var(--text-md) }` so unsized text inside portalled drawers, dialogs, and plain table/definition cells aligns with the console scale, while keeping icon buttons, standalone glyphs, and `Pager` controls sized explicitly.

## Public site & documentation

- **Edge release injection on landing routes.** Routed landing HTML paths (`/`, `/index.html`, `/zh`, `/zh/`, `/zh/index.html`) through the Cloudflare site Worker (`run_worker_first`) to inject the latest stable GitHub Release version with edge caching and versioned weak `ETag` headers, and refreshed README console screenshots.

## Upgrade notes

- Back up `.env` and your SQLite database or volume before upgrading; refer to `docs/ops/sqlite-operations.md`.
- Database migration `065_usage_price_unpriced.sql` recreates the `usage_cost_no_reprice` trigger on `usage_events`. It is forward-only and runs automatically at startup after an encrypted pre-migration backup.
- No new required environment variables or Compose changes are introduced in v0.4.4.
- Container images are available on Docker Hub as `wiziscool/oh-my-cpa:v0.4.4` and `wiziscool/oh-my-cpa:0.4.4`.
