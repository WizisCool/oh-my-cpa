# Oh My CPA v0.2.4

## Request records redesign and model display

- **One-question request cells**: The request list separates operational concerns into distinct columns. A dedicated **Mode** column shows reasoning effort on an ordinal six-step palette (`minimal` to `max`), departure marks for non-streaming calls, and a bolt icon for requests answered on a `fast` or `priority` response service tier.
- **Unified model terminology**: Standardizes model concepts across the console into three tiers:
  - **Call model**: The client-visible model alias or requested call point (`model_alias`, falling back to `model`).
  - **Requested model**: The model name that CPA routed and requested from the upstream provider (`model`).
  - **Actual / Served model**: The model the upstream reported having served in the response (`response_model`), highlighted with a swap indicator when substituted.
- **Request records model view toggle**: Operators can switch whether request records display the **Call model** or the **Requested model** directly from the request list toolbar. The choice is stored in the `omc_models_view` preference shared with the dashboard.
- **Model brand marks**: The request list, detail drawer, and filter facets display manufacturer and provider brand marks from the Model Square catalog. A new `omc_request_model_icons` preference in OMC Settings allows operators to toggle model icon visibility (enabled by default).
- **Responsive column folding & interaction**: On narrower viewports, less critical columns fold progressively rather than scrolling horizontally. Failed-request error popups maintain an accessible pointer path and allow easy error copying. Header folding settles virtual list heights in one step without frame drops.

## Configuration & gateway options

- Clarifies `passthrough-headers` and upstream response-header forwarding semantics in all four supported languages (English, Simplified Chinese, Traditional Chinese, Malay).
- Aligns omitted retry rounds and cooldown wait defaults with CPA's runtime zero values while preserving explicit YAML values and comments.
- Payload rule categories default to collapsed, automatically disclosing on validation errors.

## Upgrade notes

- Back up the persistent SQLite database and preserve its master key before upgrading; follow `docs/ops/sqlite-operations.md`.
- No new database migrations are required in this release. Existing `usage_events` records seamlessly display according to the chosen model view and brand mark settings.
- The `omc_request_model_icons` preference defaults to `true` and is persisted in the existing preferences table.
- Compose continues to default to `latest`. To pin this release after publication, use `wiziscool/oh-my-cpa:v0.2.4` or `wiziscool/oh-my-cpa:0.2.4`.
