# Oh My CPA v0.3.17

This release accepts a credential pasted into OAuth management instead of saved to a
file first, prints every amount in the console at one precision, and draws each plugin
mark as its author published it. The System page states its storage, component-health
and change-log readings once, Request Records' list keeps scrolling while its first read
lands, and a select the reader can type into opens as a bottom sheet on a phone.

## Pasted credentials

- OAuth management's **Upload JSON** action opens a dialog with **Files** and **Paste
  JSON** tabs. Files keeps the batch upload, now with a drop zone as well as a picker,
  and each chosen file keeps its own name.
- Pasted text is parsed in the browser and only the credential's provider type and
  account address are shown back; token fields are never rendered.
- The file name is suggested as `<type>-<email>.json` and stays editable, with the
  gateway's selector rules checked inline. `auth-<timestamp>.json` stands in when the
  text carries no type or address.
- A name already in use holds the upload until **Replace** is ticked, because CPA
  replaces a credential stored under the same name. An unconfirmed name is also looked
  up exactly before writing, so a name the loaded list misses — capped, or loaded before
  someone else added it — is held for confirmation rather than replaced.
- Pasted text is cleared when the dialog closes, and it is never passed through the
  query cache. The dialog cannot be dismissed while an upload is in flight, because the
  request cannot be aborted and the operator must see its outcome.
- No backend contract changed: the text goes through the existing single-file upload
  endpoint, with its name, size and single-object validation.

## One money precision

- An amount reads at two decimals, four below one cent and six below a ten-thousandth.
  The dashboard model list, request rows, request details, image export, Insights and
  the USD accounting readouts — Pricing book spend, quota balances and recorded capacity
  cost — print by that one rule, which the dashboard's cost tile already used.
- Rates are not amounts: per-1M token prices and the 1-USD quote in OMC Settings keep
  their own precision. The price editor's preview keeps sub-cent detail above a cent,
  because `$0.075` and `$0.076` are different prices that two-decimal money prints the
  same.
- The Insights cost title no longer carries a six-decimal exact value, and amounts group
  thousands consistently.

## Plugin artwork

- A plugin's mark is drawn as the artwork the registry publishes. The console had
  rendered every SVG logo as a `currentColor` alpha mask, so the opaque badges plugins
  publish — gradients, embedded images, full-bleed rounded rectangles — collapsed into
  solid blocks. CPA Credit Manager, Quota Center and Claude Seat Pacer read as their
  badges again.
- SVG and raster artwork share one isolated `<img>` path: untrusted plugin SVG still
  cannot enter the host DOM, and the CSP still only has to allow `data:` images. A
  broken mark falls back to the generic glyph, because the image reports its own
  failure.

## System page

- SQLite Storage states one footprint: the main file and the write-ahead log over one
  bar. Request-record retention reads as the share of its horizon the stored records
  fill (`4 / 90 days`) beside the oldest record's date. SHM size, journal mode, retention
  source, deleted rows, the pass schedule and the auto-vacuum row are gone; a file that
  still holds freed space keeps its rebuild notice.
- Component Health covers CLIProxyAPI, Oh My CPA and the Updater. The updater row states
  the sidecar's condition — ready, not installed, not containerised, disabled, a refused
  credential, not yet read or a failed read — and when the update check last ran. A
  failed read no longer repeats an earlier healthy verdict.
- Health and storage share a row at equal height, and Maintenance closes the page at full
  width with its three actions side by side, stacked below 900px.
- The change log drawer opens with the running version and the latest one, the release
  count and the repository link, then a release timeline whose upgrade-range releases
  take an accent node. Release notes render tables, blockquotes and rules.
- On a phone the update check keeps the title's line with a 40×40px target and its
  accessible name.

## Request list scrolling

- A wheel notch on Request Records during the first load no longer swallows the first
  real scroll: the top correction is armed only when the notch lands inside a mounted,
  scrollable list, and is cleared on expand, view change and the top bounce. Shift, Alt,
  Ctrl and horizontal wheels belong to the platform again.
- A glide now hands the list its offset, so the list stays the only writer of its own
  position and steps no frame late. The visible rows keep stable ref callbacks, so a
  scroll frame no longer re-attaches and measures them: sixteen notches on a
  4×-throttled CPU fell from 644 row measurements to 215.

## Selects on narrow screens

- A select the reader can type into opens antd's popup on a desktop and a bottom sheet
  below the shell's 900px breakpoint. The sheet opens without the keyboard, scrolls as
  an ordinary touch list at 48px rows with the current choice in view, and holds the
  height it opened at while the list narrows. A single-select picks and closes;
  multi-select and tags keep the sheet open behind a **Done** action.
- That covers display currency, time zone, OAuth connect, model rules, the warmup model,
  the request toolbar and advanced-filter facets, export mask columns, the log path
  filter, model modalities and service tiers. A sheet opened inside a drawer no longer
  pushes the side panel off a phone screen.

## Insights comparison label

- A running calendar window is compared with the same elapsed stretch of the previous
  period — at 03:57, today against yesterday 00:00–03:57 — so the tile now reads
  **Prev. same time** rather than looking like the previous period's total.
- Tiles, ranking rows and the key table's change column carry the compared window's
  instants as their title, and a comparison crossing the new year prints the year at
  both ends. The label is derived from the resolved window, so it cannot drift from the
  figure beneath it.

## Upgrade notes

- Back up `.env` and the data directory or volume before upgrading; follow
  `docs/ops/sqlite-operations.md`.
- No new database migration is introduced. An install upgrading from v0.3.16 keeps
  schema version 052 (`052_credential_display_names.sql`), and existing data and settings
  are untouched.
- No environment variable, Compose file or configuration change is required; the
  differences are in the served console.
- Compose continues to default to `latest`. After publication, pin this release with
  `wiziscool/oh-my-cpa:v0.3.17` or `wiziscool/oh-my-cpa:0.3.17`.
