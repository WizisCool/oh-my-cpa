# Oh My CPA v0.4.5

Oh My CPA v0.4.5 eliminates frame drops when switching to the Dashboard and Insights routes, aligns the Dashboard Total cost tile caption and Configuration dirty-bar button styling, keeps Agent workspace notices clear of the empty-state hero, and updates the public landing page with a live routing map, provider marquee, and step-by-step installation flow.

## Dashboard & console performance

- **Hot-route slot retention for read-only observability views.** Kept `/dashboard` and `/insights` mounted inside bounded `content-visibility: hidden` slots (`HotRouteSlot`) with frozen router context snapshots and `RouteActivityContext` polling, live-stream, and clock pauses when inactive, revalidating stale queries on reactivation while continuing to unmount credential-bearing and draft-owning routes on exit.
- **Zero-dependency monotone SVG sparklines.** Replaced Recharts sparklines in `DashboardTrendChart` with a lightweight monotone cubic Hermite (`curveMonotoneX`) SVG sparkline featuring logical `viewBox` coordinates, scaled pointer scrubbing, keyboard navigation (`ArrowLeft`, `ArrowRight`, `Home`, `End`, and `Escape`), shared touch-tooltip dismissal, and polite live-region readouts.
- **Frame-budgeted mounts and reduced layout thrash.** Pooled `ChartContainer` sizing onto `sharedResizeObserverHub`, added per-priority frame-scheduler slice caps while preserving `DeferredPanel` staging, deferred `RollingNumber` `<NumberFlow>` hydration until after initial formatted paint, gated `FilterTransition` layout snapshots on item-key changes, removed synchronous layout reflows in `TokenHeatmap` and `RoutingMap`, and memoized `useIdentityDirectory` projections with a `WeakMap`.

## Console layout & visual alignment

- **Aligned Total cost KPI tile caption across pricing states.** Replaced `costNoteKey` with `resolveCostCaption` on Dashboard so the **Total cost** card keeps a consistent single-line caption rhythm aligned with sibling KPI tiles (`RPM`, `TPM`, `Cache rate`): showing the per-request average when all requests are priced, `Partial` with an unpriced-models link (or `Priced {priced}/{total}`) when partially priced, and `No prices` or `No priced requests` when unpriced, with full explanations moved into a keyboard-focusable tooltip.
- **Standardized Configuration dirty-bar button variants.** Removed the custom `.config-dirty-btn-*` color and size overrides in `ConfigDirtyBar` so **Save changes** renders as the shared tactile ink `primary` button and **Discard** uses `ghost` at the default 32px control height.
- **Column-aligned Agent notices above the empty-state hero.** Wrapped Agent workspace notices in the shared `.notices` column container and switched hero centering from `justify-content: center` to `auto` vertical margins on the empty-state body so top notices no longer overlap the empty-state hero across desktop, short viewports, or mobile keyboards.

## Public landing site

- **Live routing map, provider marquee, and numbered installation steps.** Ported the console's routing map tile and lane geometry with success-only pulses and rolling request/cost counters to `deploy/site/landing/`, added a hover-pausing provider marquee, introduced bidirectional scroll-driven reveals (with an `IntersectionObserver` fallback) and pointer-tilted hero artwork, and replaced the terminal window with numbered, per-step copyable installation commands (renaming the existing-gateway tab to **Existing CPA** and the primary CTA to **Quick start**).

## Upgrade notes

- Back up `.env` and your SQLite database or volume before upgrading; refer to `docs/ops/sqlite-operations.md`.
- No new database migrations, environment variables, or Compose changes are introduced in v0.4.5.
- Container images are available on Docker Hub as `wiziscool/oh-my-cpa:v0.4.5` and `wiziscool/oh-my-cpa:0.4.5`.
