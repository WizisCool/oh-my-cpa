# Oh My CPA v0.4.0

Oh My CPA v0.4.0 is a major architectural release built around two foundational upgrades: a complete rebuild of the web console UI layer and a faster, coordinated backend middleware and analytics pipeline. On the frontend, the console retires Ant Design, ECharts, and `dayjs` in favor of headless `shadcn/ui` + `@base-ui/react` primitives, Tailwind CSS v4 design tokens, `recharts`, and an open runtime Theme SDK—cutting startup JavaScript by ~25% and unifying overlays, tooltips, and motion across every surface. In the backend and middleware layer, a new in-memory `StateCoordinator` coalesces configuration writes over a 250ms write-behind window with live SSE reconciliation, a unified outbound network policy governs external traffic across the console, CPA, updater, and backups, and SQLite usage folding, pricing lookups, and Insights pivots have been re-engineered for multi-hundred-thousand-row workloads.

## Frontend UI architecture overhaul

- **Headless component foundation (`shadcn/ui` + `@base-ui/react` + Tailwind v4).** Retired `antd`, `@ant-design/*`, `@rc-component/*`, `dayjs`, and `echarts` across the console (dropping 114 transitive packages and shrinking startup `initialJS` by ~25% gzip and `vendor-charts` by ~48.5% gzip). Rebuilt inputs, selects, comboboxes, dialogs, alert dialogs, sheets, menus, tabs, accordions, tables, and toast notifications on accessible Base UI primitives wired directly to OMC design tokens.
- **Open Theme SDK and unified visual craft.** Added a declarative runtime Theme SDK (`ThemeContract`, `OMCThemeManifest`, `registerTheme`) alongside the six built-in palettes (`omc-dark`, `omc-light`, `pewter`, `fog`, `forest`, `sandstone`) with solved per-palette edge/elevation shadows, a five-step concentric corner scale, `ZonedDate` over cached `Intl.DateTimeFormat` for DST-safe calendar arithmetic, and `react-markdown` + `remark-gfm` for streaming Markdown.
- **Rebuilt charts, unified tooltips, and disciplined motion.** Rebuilt all seven Dashboard and Insights charts on `ChartContainer` + `recharts` with compositor view transitions (`useChartMorph`). Unified all tooltip surfaces onto `@base-ui/react/tooltip` (`TipCard` / `TooltipReadout`) with touch dismissal, added smooth list filter transitions, enforced modal-over-drawer stacking, refreshed the sign-in stage, and added `RoutingMapSkeleton` for live routing load states.

## Middleware, state coordination & pipeline optimization

- **In-memory `StateCoordinator` and SSE live reconciliation.** Added `internal/statecoord` and `/api/events` (`/api/v1/events`) SSE streams alongside `GET /api/v1/management/state`. High-frequency configuration slices (`scalars`, `client_keys`, `openai_compat`, provider families, OAuth rules, and auth-file status) are served from an `RWMutex`-protected hot projection, rapid writes coalesce across a 250ms write-behind window (with `X-OMC-Sync: 1` for immediate synchronous flushes and pre-write gate draining for structural writes), and optimistic React mutations reconcile silently without flicker.
- **Unified outbound network proxy policy.** Added **OMC Settings → Network proxy** (`environment`, `direct`, or encrypted `proxy` with `NO_PROXY` exclusions) backed by `internal/outbound` and synchronized with CPA's `requests.proxy-url`. The selected route governs OMC release/manifest checks, OpenRouter pricing sync, Frankfurter exchange rates, Google Fonts, provider probes without their own proxy, updater image downloads (via `go-containerregistry` streaming import with no silent fallback), and compatible remote backup adapters.
- **End-to-end usage, pricing, and analytics speedups.** Consolidated `AggregateUsageFacts` into a single `usage_events` scan staged through `temp._omc_usage_fold_15m`, replaced full-history key mask scans with top-of-index probes, bounded live-tail counts in `ListUsageEvents`, switched `StatsUsagePipeline` to O(1) endpoint seeks, moved 30-day pricing usage onto hybrid facts+tail reads with batched suggestions and cached catalog reads, and rewrote Insights cube pivots with typed-array accumulators.

## Quota forecasting & OAuth credential workspace

- **Per-cycle capacity evidence and model forecasts.** Separated long-lived capacity calibration from rolling snapshot retention into `quota_capacity_cycles`. Quota windows now project model-conditioned remaining requests, tokens, and monetary forecasts alongside mixed-model calibration and normalized Kimi counted usage windows.
- **Redesigned OAuth fleet workspace.** Gave each OAuth provider its own credential surface, animated quota bars with streaming batch refresh readings, surfaced model-level disabling, simplified excluded-model editing with drag-reorderable OAuth model rules, and pinned credential recovery through the issuing `oauth_provider` portal.

## Dashboard, Insights, keys, configuration & deployment

- **Dashboard and Insights.** Added calendar period views, a printable usage receipt, adaptive open-calendar buckets with pace comparison, an outlier-resistant previous-period baseline, single-bar model usage rankings, and always-on live SSE request streaming.
- **API keys, gateway configuration, and cooldowns.** Redesigned API key management to match gateway lists (`PUT /management/api-keys/{index}`), exposed CPA's server shutdown drain timeout, added Anthropic refusal fallback and `sensitive-words-replace` map editing, added Meta protocol targeting in payload rules, and surfaced forced credential cooldowns (`force_cooldown`).
- **Deployment language pin and demo sandbox.** Added `OMCPA_DEFAULT_LANGUAGE` to pin the console's default reading language (`zh`, `zh-Hant`, `en`, `ms`, or `auto` for browser detection), rebuilt the demonstration dataset with on-demand generation, and added an interactive browser-local demo sandbox.

## Upgrade notes

- Back up `.env` and your SQLite database or volume before upgrading; refer to `docs/ops/sqlite-operations.md`.
- Database migrations `060_quota_capacity_cycles.sql`, `061_outbound_proxy_settings.sql`, and `062_usage_force_cooldown.sql` are forward-only and run automatically at startup after an encrypted pre-migration backup.
- **Network proxy defaults to your existing environment.** `outbound_proxy_settings` starts unconfigured (`environment` mode), preserving existing `HTTP_PROXY`/`HTTPS_PROXY` variables, CPA `requests.proxy-url`, and Docker daemon pull behavior. If you switch to an explicit proxy or direct image-pull route, both the console and updater sidecar must be on a build supporting that route; older sidecars safely refuse proxy/direct image pulls until upgraded.
- **Default language environment variable.** `OMCPA_DEFAULT_LANGUAGE` defaults to unset (browser detection). Docker Compose setups copied from earlier releases must add `OMCPA_DEFAULT_LANGUAGE: ${OMCPA_DEFAULT_LANGUAGE:-}` under the service's `environment:` block to forward `.env` values into the container.
- Container images are available on Docker Hub as `wiziscool/oh-my-cpa:v0.4.0` and `wiziscool/oh-my-cpa:0.4.0`.
