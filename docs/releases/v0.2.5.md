# Oh My CPA v0.2.5

## Request log viewer

- **Read a request's log in the console**: On the gateway log, a request id is a link that opens CPA's log file for that request in a side panel, with copy and download in the footer. Request-error log files gain a **View** action beside download. A file larger than 2 MiB is offered for download instead of being rendered.
- **Requests the request list never holds**: A request CPA refuses before it chooses a credential (for example `503 auth_unavailable` while the only credential is cooling down) publishes no usage record, so it does not appear in request records or failure statistics. Its log line still carries a request id, and the viewer reads the log from that id.
- **Retention is stated, not hidden**: CPA keeps a per-request file only while request logging is on, and otherwise only its newest error logs. When no file exists for an id, the panel says so instead of reporting a failure.
- The read goes through the new session-protected route `GET /api/v1/management/request-logs/{id}`, is recorded in the audit log, and is refused in demo mode.

## Pricing for OAuth model aliases

- Pricing discovers both the client alias and its billable upstream from enabled OAuth credentials and provider-wide OAuth alias rules, including replacement aliases. An upstream can be linked to a price even when clients only ever see its alias.
- Request records lead with the client alias in the call-model view and show the routed upstream on a secondary line; a served-model substitution keeps priority on that line.
- If alias discovery fails, the last complete pricing catalog is kept.

## Console interface

- **Switches**: Every on/off control is one component that states its value by thumb side, track fill and a mark on the track, with a pending state and a 44×24 touch target under a coarse pointer.
- **Inline notices**: Notices and load failures carry a tone rule and a tone code (`INFO`, `WARNING`, `ERROR`, `SUCCESS`). A Playground refusal and a requested update check that fails are toasts.
- **Side panels, empty states, tags, confirmations, pagers and meters** share one design across pages: three panel widths, a named close control, and destructive confirmations with a danger button.
- **OAuth credential list**: The header and every record share the same column edges.
- **Details**: Request detail fields align label and value on opposite edges; copy buttons acknowledge in place with a check mark; dashboard tiles use the narrow-screen inset on phones; quota bars use the console's 2px corner.

## Upgrade notes

- Back up the persistent SQLite database and preserve its master key before upgrading; follow `docs/ops/sqlite-operations.md`.
- No new database migrations, environment variables or preferences are introduced in this release.
- Request-time price locks stay immutable: linking an upstream prices future requests, and earlier unpriced requests are not backfilled.
- The request log viewer needs CPA's file logging to be on to list requests, and CPA's request logging to keep a file for requests that did not fail.
- Compose continues to default to `latest`. To pin this release after publication, use `wiziscool/oh-my-cpa:v0.2.5` or `wiziscool/oh-my-cpa:0.2.5`.
