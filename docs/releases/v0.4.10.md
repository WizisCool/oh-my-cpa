# Oh My CPA v0.4.10

Oh My CPA v0.4.10 unifies all background refresh schedules under OMC Settings with independent release and plugin update-check intervals, adds dedicated GitHub Token management and rate-limit probing in OMC Settings, and standardizes selection bars and grouped toast list rendering across the console.

## Unified Refresh Schedules & OMC Settings

- **Single background refresh scheduler.** Consolidated `pricing_sync`, `exchange_rates`, `model_provenance`, `quota_auto_refresh`, `release_updates`, and `plugin_updates` into a unified `internal/refresh` scheduler with immediate wake-on-preference-change and clean shutdown.
- **Independent release, plugin, and exchange-rate schedules.** Split `omc_update_check` into separate `interval_minutes` (OMC & CPA releases) and `plugin_interval_minutes` (plugin store updates) controls (`0` for off, or `15–1440` minutes, defaulting to `60`, while staying backward-compatible with single-field `interval_minutes` payloads). Added `omc_exchange_rate_refresh` (`0` or `1–168` hours, defaulting to `24`) and `GET /api/v1/pricing/sync-schedule`.
- **Automatic Refresh group in OMC Settings.** Grouped OMC/CPA release checks, plugin store update checks, scheduled quota refresh, OpenRouter pricing auto-sync (synchronized with `/pricing`), and display exchange-rate refresh into one **Automatic Refresh** section under **OMC Settings**.

## GitHub Token Management & Rate-Limit Probe

- **Dedicated GitHub Token card in OMC Settings (`/omc-settings#github-token`).** Manage CPA's `server.github-token` directly via `GET/PUT /api/v1/management/github-token` with revision checking, pre-write encrypted backup, fail-closed `github_token.save` and `github_token.clear` audit events, readback verification, and immediate cache invalidation while remaining synchronized with **Configuration** and `config.yaml`.
- **Live GitHub `/rate_limit` probe and direct error links.** Added `POST /api/v1/management/github-token/test` to inspect token status and remaining quota (`valid`, `anonymous`, `invalid`, `error`) without leaking secrets, and updated GitHub 429 and token error guidance across System, Plugins, and Config views to link directly to `/omc-settings#github-token`.

## Console Selection Bars, Toast Lists & Docs

- **Unified selection bar anatomy and action weight.** Standardized `SelectionBar` across OAuth Management (`BatchActionBar`) and Usage Events (`RequestSelectionBar`) with a leading clear glyph, consistent desktop and mobile order, quiet link scope controls, shared ghost action weight with separated delete styling, and per-action busy spinners scoped to the triggered handler.
- **Inset toast item list shadow and single scroll owner.** Switched `.omc-toast-items` to `--surface` with an inset `--shadow-well` and `--float-rule` dividers while letting the toast body own vertical scrolling so per-target item lists do not clip shadows.
- **Refreshed documentation screenshots.** Updated English and Chinese README screenshots to reflect current console views.

## Upgrade notes

- Back up `.env` and your SQLite database or volume before upgrading; refer to `docs/ops/sqlite-operations.md`.
- No database migrations, new required environment variables, or Compose changes are introduced in v0.4.10. Existing `omc_update_check` preferences remain compatible, and any existing `server.github-token` in `config.yaml` is surfaced masked under **OMC Settings**.
- Container images are available on Docker Hub as `wiziscool/oh-my-cpa:v0.4.10` and `wiziscool/oh-my-cpa:0.4.10`.
