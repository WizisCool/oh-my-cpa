# Oh My CPA v0.3.15

This release masks OAuth accounts across request records and the dashboard quota panel,
adds a time-bucket activity strip to the dashboard providers list, introduces an
on-demand CPA model catalog refresh in Model Square, automatically rebinds dependent
containers sharing a replaced network namespace during updates, and weighs
period-over-period Insights changes by request sample evidence.

## OAuth account masking

- Request Records (table rows, filters, active chips, detail drawer, and JSON export)
  and Insights credential labels now mask OAuth accounts using `maskAccount`
  (`op•••r@example.com`, Vertex project IDs) rather than printing raw email addresses or
  project IDs.
- The dashboard credential quota panel masks credential accounts in both the row label
  and hover title. There is no reveal affordance on the dashboard; raw addresses remain
  scoped to `/oauth-management`, which owns per-row address reveals.
- Account projections trim before selecting fallback candidates, ensuring an address
  holding only whitespace does not shadow an adjacent project ID or file name.

## Dashboard provider activity timeline

- AI Providers on the dashboard adds a per-provider activity strip by time bucket
  (`bucket_ms` from `GET /management/dashboard/providers`), rendering request activity
  over the selected window on a shared timeline.
- Sparse buckets map onto the grid and color according to OMC's standard 80%/50%
  success-rate bands, while idle buckets remain on the neutral track. Tooltips report the
  interval, request count, and success rate.
- The strip provides an accessible keyboard focus stop summarizing active buckets. It is
  omitted on mobile displays while the overall success rate remains visible.
- The redundant failed-request count beneath the traffic bar is removed.

## Model Square catalog refresh

- Model Square adds an explicit on-demand catalog refresh action backed by
  `POST /management/model-square/refresh-catalogs` and CPA's
  `/v8/management/routing/model-definitions/refresh`.
- The action updates general, Codex client, and Devin catalogs with audit tracking
  before and after execution, returns a handwritten projection preserving partial HTTP
  502 outcomes with allowlisted error categories, and provides localized feedback across
  all four languages.
- On completion, Model Square immediately re-reads displayed models, prices, and
  recent-request counts, and invalidates OAuth/credential model caches. The refresh is
  refused in demo mode.

## Updater container namespace rebinding

- When deployments run the console, the updater sidecar, or other services inside the
  gateway's network namespace (`network_mode: container:<gateway>`), replacing the gateway
  container no longer leaves joined containers disconnected.
- The updater discovers running containers sharing the replaced container's network
  namespace and re-creates them in Compose `depends_on` order with their exact running
  images after gateway replacement or restoration.
- When the updater itself is joined to the replaced namespace, it hands its identity and
  completed job state to a successor in the replacement namespace via `ENV_LAST_JOB`.
- Inherited hostnames are removed on `container:` network modes to satisfy Docker daemon
  requirements, updater self-identification (`selfContainerID`) is hardened, and
  rollbacks handle unrecoverable namespace dependents safely.

## Evidence-weighted Insights comparisons

- `compareMetric` in Insights now weighs period-over-period metric comparisons by request
  sample evidence using Poisson standard errors with Haldane's ½ correction.
- Metric variations within 1.96 standard errors are labeled "Within normal variation"
  without misleading trend tones.
- Significant increases from a baseline smaller than sampling noise display **New**
  instead of extreme percentage spikes (such as +6000%).
- Spend comparisons count only priced requests. Metric tiles, rankings, and key tables
  share the same comparison rules.

## Upgrade notes

- Back up `.env` and the data directory or volume before upgrading; follow
  `docs/ops/sqlite-operations.md`.
- No new database migration is introduced. An install upgrading from v0.3.14 keeps schema
  version 050 (`050_exchange_rate_cache.sql`). Existing data and settings are untouched.
- Deployments using `network_mode: container:<gateway>` for OMC or the updater sidecar
  can now safely perform gateway container updates without manual container restarts.
- Compose continues to default to `latest`. After publication, pin this release with
  `wiziscool/oh-my-cpa:v0.3.15` or `wiziscool/oh-my-cpa:0.3.15`.
