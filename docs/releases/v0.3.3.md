# Oh My CPA v0.3.3

This patch makes the console's live readings clearer and fixes the cases where a derived
value could report the wrong thing. The live routing map keeps a model's identity separate
from the result, the console offers CPA's Claude session date pin retention, TPS no longer
counts hidden reasoning against the post-first-token window, and a followed update reports
one end. The verified gateway baseline remains CPA **v8.0.31**, plus the Claude setting CPA
introduced in v8.0.32; CPAMC remains **v1.26.5**.

## Configuration

- **Claude session date pin retention.** The Claude Behavior group on the settings page now
  edits `upstream.claude.session-date-pin-days`, the number of days CPA keeps a session's
  cloaked date pin before re-anchoring it. The field defaults to 7 days; an explicit `0`
  keeps CPA's continuity-scoped pin and survives a save and reload as `0`. An untouched
  gateway is never written, because the default reproduces the key's absence.
- **Cleared number boxes mean the omitted setting.** Clearing a number field now restores
  the field's semantic default instead of writing `0`, so a gateway that treats an absent
  key differently from zero is not changed by an empty control. A saved zero remains a
  value, and the rest of the configuration file is left alone.

## Live routing

- **Identity is not a verdict.** Model lanes use the routing palette's cool identity
  colours, while credential lanes stay neutral. Success, warning and failure remain on the
  credential node's wash, port ring and row text, so a red or green line can no longer be
  read as the model's identity.
- **The trip plays everywhere.** The routing map's request trip, lane flow, node glow and
  row motion play for every reader, including when the system reports
  `prefers-reduced-motion: reduce`; on Windows that includes turning Animation effects off
  for performance. The exception is scoped to this map, whose travel is the reading itself;
  every other console animation still honours the preference. ADR 0102 records the
  trade-off.
- **The public demonstration moves.** Its Worker now derives deterministic simulated
  gateway traffic from the wall clock and streams it through the same routing and live
  endpoints as a real deployment, so the demonstration shows requests, reroutes, failures
  and cooldowns instead of a static capture.

## Request and update readings

- **Hidden reasoning no longer inflates TPS.** In `exclude_ttft` mode, a record that reports
  reasoning tokens now uses total latency. OpenAI and Codex encrypted reasoning and Gemini
  thoughts are generated before the first visible token, so dividing all output tokens by
  the post-first-token tail overstated the rate. The revised fallback hint explains the
  reasoning-token case in every console language. Stored timings and usage are unchanged.
- **One update, one end.** A console update is now reported once per updater job id. If the
  updater stops answering and later returns still naming the job the page gave up on, the
  page does not follow it again or show a second "outcome unknown" warning. A later update
  with a new job id is followed normally.

## Upgrade notes

- Back up `.env` and the data directory or volume before upgrading; follow
  `docs/ops/sqlite-operations.md`. **This release adds no SQL migration**: the schema
  remains at `043_channel_model_prices.sql`.
- No new environment variables and no new Oh My CPA preferences. The Claude date-pin field
  edits CPA's existing `upstream.claude.session-date-pin-days` key; a gateway that predates
  that key refuses the write, while leaving it untouched is always safe.
- The reduced-motion exception is limited to the live routing map. All other motion follows
  the system preference as before.
- The live endpoints, routing DTOs and dashboard layout preference are unchanged.
- Compose continues to default to `latest`. After publication, pin this release with
  `wiziscool/oh-my-cpa:v0.3.3` or `wiziscool/oh-my-cpa:0.3.3`.
