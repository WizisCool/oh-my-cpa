# Oh My CPA v0.4.11

Oh My CPA v0.4.11 onboards the GitHub Copilot OAuth credential family and global OAuth request-scoped error rules, exposes CPA deployment server identity (`server.server-id`), aligns Claude subscription plan detection with Team, Team Premium, Enterprise, and Ultra accounts, adds manual quota refresh on `/trends`, and refines System versions, status labels, and GitHub token controls.

## Copilot OAuth Family & Global OAuth Error Rules

- **GitHub Copilot credential family support.** Registered `copilot` (`GitHub Copilot`) in credential metadata, primary provider filters, Dashboard OAuth channel aggregation, Model Square `copilot/` prefix normalization, Microsoft `mai-*` model family recognition, and reserved plugin provider keys so community login plugins can supply Copilot flows safely.
- **Global `oauth.request-scoped-errors` management.** Added `GET/PATCH /api/v1/management/auth-files/request-scoped-errors` with pre-write encrypted backups, readback verification, fail-closed `oauth_request_scoped_errors.update` audit logging, `StateCoordinator` SSE synchronization, and a new **Error rules** tab in `OAuthModelRulesDrawer` reusing `ErrorRulesEditor`.

## CPA Deployment Identity & Claude Quota Accuracy

- **CPA deployment server identity (`server.server-id`).** Exposed `cpa.server_id` on `GET /api/v1/management/system` and diagnostics (`cpa_server_id`) using `GET /v8/management/server/server-id` with `X-CPA-SERVER-ID` header fallback for CLIProxyAPI v8.1.0+, protected stored server IDs against ancestor removals in `configyaml`, and added a copyable, validated UUIDv4 `server.server-id` editor under **Configuration**.
- **Claude subscription plan detection.** Updated `ParseClaudeProfile` to evaluate active `organization_type` and `seat_tier` alongside `rate_limit_tier` before consumer account flags, accurately distinguishing `Claude Team`, `Claude Team Premium`, `Claude Enterprise`, `Claude Ultra`, `Claude Max`, and `Claude Pro` while ignoring inactive organizations.

## Trends, System & Console Polish

- **Manual quota refresh in Trends.** Added a persistent refresh action to the **Subscription quota trends** (`QuotaBurnPanel`) toolbar on `/trends` sharing `canRefreshTrendsQuotaCredential()` eligibility rules and updating burn-rate and exhaustion forecasts before completing.
- **Event-scoped status chips & side-by-side Versions card.** Reserved tinted `StatusLabel` chips for event outcomes (requests, audit events, backup jobs, warmup runs) while keeping state indicators as quiet pips and words, and redesigned the System **Versions** card to show OMC and CPA side by side with inline update actions.
- **GitHub token, danger button, and brand polish.** Moved GitHub token quota probe results to keyed toasts (`github-token-test`), toned down resting secondary destructive buttons until hover/focus/confirmation, bound `<code>` elements to `--font-mono`, and updated `docs/images/social-preview.png` alongside reproducible social preview rendering.

## Upgrade notes

- Back up `.env` and your SQLite database or volume before upgrading; refer to `docs/ops/sqlite-operations.md`.
- No database migrations, new required environment variables, or Compose changes are introduced in v0.4.11.
- `server.server-id` and `cpa.server_id` support CLIProxyAPI v8.1.0 and later; older gateways omit `cpa.server_id` cleanly.
- Container images are available on Docker Hub as `wiziscool/oh-my-cpa:v0.4.11` and `wiziscool/oh-my-cpa:0.4.11`.
