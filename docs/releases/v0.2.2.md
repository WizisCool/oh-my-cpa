# Oh My CPA v0.2.2

## Brand

- The square brand mark is redrawn as a gauge ring. The mark appears in the collapsed
  navigation rail, on the Agent authorization page and in the browser tab, and is now a ring
  on the wordmark's letter grid, cut twice, with its lower trailing corner filled in the
  accent — a gauge with part of its allowance spent. The ring follows the foreground colour
  and the corner the accent, so the mark still moves with an operator's own accent, and the
  wordmark and the palettes are unchanged.
- The favicon holds both default palettes behind the browser's light/dark preference, because
  a browser tab has no console theme to follow.

## Console fixes

- In the OAuth management model rules drawer, the alias table's remove action could sit past
  the drawer's trailing edge with nothing indicating the row ran wider than the drawer. The
  upstream model column now takes the remainder beside fixed sibling widths, so the whole row
  fits the drawer at desktop width. The remove column is pinned to the trailing edge, so a
  phone that still scrolls the fields sideways keeps the removal control in view.

## Upgrade notes

- Back up the persistent SQLite database and preserve its master key before upgrading; follow
  `docs/ops/sqlite-operations.md`. This release adds no database migration beyond v0.2.1 and
  does not change its retention defaults.
- Both changes are console-side only. No management-endpoint read, environment variable or
  key scope changes with this release.
- Compose continues to default to `latest`. To pin this release after publication, use
  `wiziscool/oh-my-cpa:v0.2.2` or `wiziscool/oh-my-cpa:0.2.2`.
