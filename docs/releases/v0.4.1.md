# Oh My CPA v0.4.1

Oh My CPA v0.4.1 builds on v0.4.0 with whole-window subscription capacity estimation, reliable Codex and Antigravity warmup rollover across window resets, a persistent non-secret identity archive for disabled or deleted credentials and providers, and console-wide selection, contrast, and request-list polish.

## Quota capacity & live countdowns

- **Whole-window capacity estimation with prior-cycle fallback.** Replaced per-model quota forecasts with direct full-window capacity estimates (`capacity` on quota windows and `quota_get_capacity`) scaled from recorded window consumption and the upstream used percentage (`current_window`). Estimates support mixed-model traffic, surface partial-pricing cost floors (`≥ $…`) or token and request totals when unpriced, freeze at the initial `100%` exhaustion boundary so paid extra-usage overflow does not inflate capacity, measure post-reset deltas after mid-cycle resets, reconcile late usage arrivals via `usage_events` insertion watermarks, and carry forward the previous completed same-plan cycle (`previous_window`) when a fresh window is at `0%`.
- **Consistent Codex 5-hour countdowns.** Distinguished genuinely unstarted Codex 5-hour windows from active cycles whose usage still rounds to `0%`, so OAuth management lists, credential cards, and the quota details drawer agree on showing `5h` versus the active remaining countdown.

## Window warmup & task organization

- **Codex and Antigravity rollover across resets.** Preserved arrived reset boundaries across zero-usage snapshots when Codex or Antigravity publishes the next cycle's future reset timestamp with `0%` usage, confirmed Codex sliding zero-usage windows across two observations before firing idle warmups, separated `429`/`5xx` quota read backoff from shorter deferred provider-gate pauses, and serialized task saves and mark updates inside single SQLite transactions.
- **Provider-grouped warmup tasks and drag reordering.** Grouped warmup tasks by provider in catalog and OAuth section order, added pointer and keyboard reordering (`omc_warmup_task_order`), and fixed `Combobox` selection display when an explicit empty-string option such as `Auto (<model>)` is active.

## Persistent identity archive

- **Unified identity directory across disables and deletions.** Added forward-only SQLite tables (`archived_credentials` and `archived_providers`) and `GET /api/v1/management/identity-directory` storing sanitized display metadata (custom/provider names, upstream names, sanitized public base URLs, icon references, plugin portal titles/logos, masked accounts, key masks, and internal-only HMAC key fingerprints). Disabled OpenAI-compatible providers whose runtime `auth_index` CPA omits, as well as deleted providers, auth files, and plugins, keep their names, marks, and key masks across Dashboard Routing, Usage Events and Exports, Insights, Pricing, and the Demo Sandbox while refusing ambiguous fallbacks.

## Console UI & selection polish

- **Lifted selections and docked batch bars.** Selected tiles, cards, and options now lift with `--shadow-selected` and `--select-surface` instead of outlines (reserving the accent ring for keyboard focus), `SelectionBar` docks over the foot of its list without shifting rows, controls and tags share consistent height and geometry, and OAuth credential checkboxes stay hidden until selection starts.
- **Dark/light thumb contrast and DataTable alignment.** Derived `--thumb-bg` across all built-in, external, and custom themes so `Segmented`, `ToggleGroup`, and mobile `StatTiles` thumbs separate cleanly from `bg-field` on every surface, improved unselected tab contrast, and added `data-slot="table-row"` to `DataTable` rows.
- **Grouped request-list banding and balanced columns.** Request rows alternate cleanly between two dedicated surface tones counted per position within each group even with interleaved arrivals, and columns use balanced fixed tracks across request, performance (accommodating long TTFT values), and key/user-agent groups.

## Maintenance, release pipeline & documentation

- **Dependency and pipeline updates.** Bumped `go.opentelemetry.io/otel/trace` from `1.45.0` to `1.47.0`, split native release builds into per-target jobs gated with Go, frontend, and browser verification before Docker publication, automated daily README screenshot refreshes, and updated English and Chinese README descriptions and screenshots.

## Upgrade notes

- Back up `.env` and your SQLite database or volume before upgrading; refer to `docs/ops/sqlite-operations.md`.
- Database migration `063_identity_archive.sql` creates `archived_credentials` and `archived_providers`. It is forward-only and runs automatically at startup after an encrypted pre-migration backup.
- `omc_warmup_task_order` is a new UI preference row and requires no manual migration.
- Agent/MCP consumers reading `quota_list`, `quota_refresh`, or `quota_get_capacity` now receive `capacity` / `capacity_unavailable` instead of the removed `model_forecasts` / `forecast_unavailable` fields.
- Container images are available on Docker Hub as `wiziscool/oh-my-cpa:v0.4.1` and `wiziscool/oh-my-cpa:0.4.1`.
