# Oh My CPA v0.4.7

Oh My CPA v0.4.7 brings persisted client-agent attribution and pre-aggregated client rollups across Insights, Dashboard, and Request Explorer, expands CLIProxyAPI v8.0.77 configuration and OAuth alias parity, refines Dashboard cache-rate and Quota displays, prints startup build diagnostics, and hardens chunk recovery after upgrades.

## Insights, Dashboard & Client Attribution

- **Persisted client attribution & pre-aggregated client rollups.** Migrations `067_usage_events_client_agent.sql` through `070_repair_codex_desktop_client_agent.sql` persist `client_agent` and `client_prefix` on `usage_events`, repair partial `usage_facts_*` partitions, and add `usage_client_facts_15m` / `usage_client_facts_daily` rollups folded alongside usage ingestion and unpriced backfill. Client recognition covers HermesAgent camelCase, Codex-compatible user agents, and Codex Desktop (`codex-cli`).
- **Insights token anatomy, client attribution & interactive drill-downs.** Added the Token Anatomy strip, a Client Attribution ranking panel (`/api/v1/management/insights/clients`), steady rankings, rolling metric figures, lifted ranking selection with a page-wide `client_agent` filter, and gliding drill-downs to Request Explorer (`?client_agent=...`), with matching client-filtered Insights cube parity in the public demo worker.
- **Dashboard client lens & continuous cache-rate wave.** Added **Models** / **Clients** lens tabs (`group_by=client` on `/api/v1/management/dashboard/models`) to the Dashboard Token Trend and Usage cards, showing client attribution and the request-retention horizon (`covered_from`). Updated the Dashboard **Cache rate** sparkline to interpolate smoothly across idle buckets and fit its active range instead of pinning to a fixed `0–100` scale.
- **Request Explorer client marks & drawer details.** Replaced the raw User-Agent column with normalized client marks and names (showing the raw User-Agent on hover), displayed client mark and client IP in the request detail drawer, and surfaced caller key aliases directly on detail views.

## Configuration, OAuth & Quota

- **Full CLIProxyAPI v8.0.77 `requests.payload.replace` support.** Updated **Configuration → Payload → Replacement Rules** to support `system`, `developer`, and `user` target roles, a `Role messages` / `JSON paths` target mode toggle (`target.paths`) with ordered gjson path editing and conflict repair, and `{ pattern, replacement }` regex entries with non-blocking Go RE2 syntax warnings and save-confirmation notices.
- **Case-only OAuth model alias pairs.** Aligned global and credential-scoped OAuth model alias validation with CLIProxyAPI v8.0.77 so pairs differing only by letter case (such as `glm-5` → `GLM-5`) are accepted, while duplicate aliases remain rejected case-insensitively.
- **Quota reset credits.** Listed all available reset credits inside the credential quota detail drawer.

## Startup Diagnostics, Resilience & Documentation

- **Startup build banner.** Printed `Oh My CPA Version: <version>, Commit: <commit>, BuiltAt: <built_at>` to `stderr` at server startup (skipping `mcp`, `updater`, and `database` subcommands) and recorded the startup metadata in the service log buffer, with commit and build timestamps injected in Docker and native release builds.
- **Automatic SPA chunk recovery & demo cache fix.** Added one-shot `vite:preloadError` reload recovery with cooldown when navigating across an upgrade, and stopped the Cloudflare demo worker from caching stale missing-chunk 404 responses.
- **Refreshed documentation screenshots.** Updated the English and Chinese README screenshots to reflect current Insights, Dashboard, and Request Explorer views.

## Upgrade notes

- Back up `.env` and your SQLite database or volume before upgrading; refer to `docs/ops/sqlite-operations.md`.
- Database migrations `067` through `070` run automatically at startup after creating an encrypted pre-migration backup (`*-before-migration-67.db.enc`). Backfilling `client_agent` and building `usage_client_facts_*` runs inside migration `069` (and `070` repairs Codex Desktop historical rows); on large databases this can add several seconds to first startup.
- Client attribution (`usage_events.client_agent`, `usage_client_facts_*`) follows the raw request-record retention horizon rather than permanent `usage_facts_*` totals; windows reaching earlier than retained request records report `covered_from`.
- `system` and `developer` replacement roles, `target.paths`, and `{ pattern, replacement }` regex entries in `requests.payload.replace`, as well as case-only OAuth model alias pairs, require CLIProxyAPI v8.0.77 or later.
- No new required environment variables or Compose changes are introduced in v0.4.7.
- Container images are available on Docker Hub as `wiziscool/oh-my-cpa:v0.4.7` and `wiziscool/oh-my-cpa:0.4.7`.
