# Oh My CPA v0.4.3

Oh My CPA v0.4.3 keeps console configuration in sync with external CLIProxyAPI edits, adds ordered Go RE2 `sensitive-patterns-replace` editing and Antigravity `TOS_VIOLATION` pause and appeal controls, unifies plugin cards and the settings drawer, makes live request arrivals glide without repainting, and launches the bilingual Fumadocs documentation site and redesigned landing page.

## Configuration synchronization & CPA v8.0.72 parity

- **External CPA configuration reconciliation.** Periodically checks CPA's persisted YAML and applied-runtime configuration fingerprints every five seconds, atomically replaces the full in-memory projection, invalidates dependent caches, notifies connected consoles over SSE, validates pending write-behind batches against the current baseline before mutating upstream state, preserves newer pending intents across delayed hot reloads, and tracks unique credential identity across regenerated provider indexes.
- **Ordered `sensitive-patterns-replace` rules for Antigravity and Devin.** Added the `pattern_rules` visual editor (`PatternRulesEditor`) with drag and keyboard reordering (`RowReorder`), Go RE2 validation, IME-safe shared `ComposingTextInput`, and draft rebase preservation for `oauth.providers.antigravity.sensitive-patterns-replace` and `oauth.providers.devin.sensitive-patterns-replace`.
- **Antigravity `TOS_VIOLATION` pause window and appeal links.** Exposed `oauth.providers.antigravity.tos-pause-window` (`placeholder: "0"`) in configuration, decoded and sanitized upstream `tos_appeal_url` and `tos_appeal_url_text` fields on credential records, and surfaced appeal action links in the credential detail drawer.
- **Stabilized configuration workbench layout.** Added `scrollbar-gutter: stable` on scrollable console routes, container-driven 2-column and 3-column workbench breakpoints (`@container config-page`), unified `.config-shell-band` header and toolbar alignment, automatic scroll-top resets on section, mode, and search changes, and single-group outline retention.

## Plugins, dashboard, requests & mobile UI

- **Unified plugin cards and leaner settings drawer.** Rendered installed plugins and plugin store entries on the shared `EntityCard` anatomy with two-dimensional grid reordering (`RowReorder` `layout="grid"`), consolidated license and install-record fallbacks into the drawer head so each fact is stated once, and opened settings for loaded plugins directly in place from the store.
- **Smooth live request arrivals.** Assigned stable per-record row band tones (`assignBandTones`) and compositor-driven arrival transforms (`MOTION_ARRIVAL`, respecting `data-reduced-motion`) so live SSE request arrivals glide into the virtualized list without full-list parity repaints.
- **Model usage ranking, quota contrast & shadow clipping fixes.** Standardized dashboard model usage rows to 40px height with lifted `--shadow-selected` focus, improved dark-mode contrast in the estimated quota dialog (`QuotaCapacityDialog`), and released settled disclosure and payload-rule cards from `overflow: hidden` clipping.
- **Fail-closed deletion snapshots, archive ordering & narrow-screen controls.** Refused provider deletions with `provider_archive_failed` (HTTP 500) whenever upstream catalog reads are incomplete, added monotonic `live_generation_seq` ordering for archived credential identity resolution, tightened demo sandbox claim-conflict checks, fixed coarse-pointer `Select`/`Combobox` clear-control layering, expanded the mobile update-check touch area, and kept narrow/320px `SelectionBar` controls on one line.

## Public site, bilingual documentation & API reference

- **Bilingual Fumadocs site, landing page & `/api-reference/`.** Added an isolated bilingual (EN / 简体中文) Fumadocs static documentation site under `/docs/` synced from canonical `docs/` and `docs/zh/` guides (`scripts/sync-docs-site.mjs`, `llms.txt`, and per-page Markdown), redesigned the programmatic EN/ZH landing page with Open Graph social cards, `sitemap.xml`, and `robots.txt`, moved Scalar API reference assets from `/api-docs/` to `/api-reference/`, reorganized guides into `install/`, `operate/`, `features/`, and `reference/`, and refreshed the README screenshots.

## Upgrade notes

- Back up `.env` and your SQLite database or volume before upgrading; refer to `docs/ops/sqlite-operations.md`.
- Database migration `064_identity_archive_live_seq.sql` adds `live_generation_seq` to `archived_credentials`. It is forward-only and runs automatically at startup after an encrypted pre-migration backup.
- No new required environment variables or Compose changes are introduced in v0.4.3.
- Container images are available on Docker Hub as `wiziscool/oh-my-cpa:v0.4.3` and `wiziscool/oh-my-cpa:0.4.3`.
