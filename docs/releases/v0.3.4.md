# Oh My CPA v0.3.4

This patch keeps OAuth management filters across reloads, makes request-view
preferences roll back consistently when a save fails, and explains CPA's credential
exclusion precedence in the console and Agent/MCP capabilities.

## Saved console views

- OAuth management remembers status and quota filters, sort order and page size in
  the existing server-side view preference. Explicit URL parameters still take
  precedence, and resetting filters updates the saved view.
- A refused preference write restores the previous view. If preferences cannot be
  read, OAuth controls remain usable through the URL without overwriting the unread
  server state.
- Request-record grouping and auto-refresh read the shared preference cache, so a
  failed save rolls those controls back consistently.

## OAuth model exclusions

- Provider exclusions are defaults for OAuth/file-backed credentials without a
  non-empty own list. On CPA v8.0.33 or later, a non-empty credential
  `excluded_models` list replaces provider `oauth.excluded-models` rather than
  extending it. A missing, empty or null list inherits the current provider rules.
- The model-rules introduction, alias-source warnings, catch-all notices, catalog
  counts and provider-rule deletion confirmation now explain that scope. A provider
  `*` does not establish a universal block when credentials have their own lists.
- The credential configuration drawer explains that clearing its list restores
  inheritance, not unrestricted availability. Agent/MCP descriptions and all four
  console languages carry the same guidance. CPA remains authoritative for model
  availability, and the existing audited, backed-up and readback-verified writes
  are unchanged.

## Upgrade notes

- Back up `.env` and the data directory or volume before upgrading; follow
  `docs/ops/sqlite-operations.md`. This release adds no SQL migration; the schema
  remains at `043_channel_model_prices.sql`.
- No new environment variables or preference keys are introduced. OAuth view
  persistence extends the existing preference document.
- OMC's general CPA v8.0.0 Management API baseline is unchanged. Upgrade older
  gateways to CPA v8.0.33 or later before relying on credential exclusion overrides,
  and check CPA's per-credential model list for availability.
- Compose continues to default to `latest`. After publication, pin this release with
  `wiziscool/oh-my-cpa:v0.3.4` or `wiziscool/oh-my-cpa:0.3.4`.
