# Oh My CPA v0.4.8

Oh My CPA v0.4.8 introduces the Trends workspace (`/trends`) for quota burn, performance, stability triage, and volume movers, makes the Model load profile the default view in Insights with Avg TPS, unifies console status indicators onto tinted `StatusLabel` chips, and adds CLIProxyAPI v8.0.78 configuration parity for Claude OAuth scope control and custom model catalog sources.

## Trends Workspace & Incident Triage

- **Trends APIs, repository index, and demo parity.** Added `GET /api/v1/management/trends/quota`, `GET /api/v1/management/trends/usage`, and `GET /api/v1/management/trends/telemetry` (with OpenAPI spec updates in `docs/openapi/swagger.json`), DST-safe calendar stepping, `response_model` / `served` and canonical `failure` category filtering (`rate_limited_429`, `upstream_5xx`, `stream_truncated`, `force_cooldown`, `other_failures`) on `/api/v1/usage/events`, `replay=calendar` replay support, custom Codex window duration naming, and full Cloudflare demo Worker parity. Migration `071_usage_events_completed_index.sql` adds `idx_usage_events_instance_auth_completed` on `usage_events(instance_id, auth_index, (timestamp_ms + MAX(latency_ms, 0)))` to accelerate quota trend completion-time queries.
- **`/trends` page, charts, and stability triage workspace.** Added the `/trends` console route and navigation entry featuring Quota Burn & Quota Cycles charts, Performance (TTFT, latency, streaming TPS) charts, Movers ranking, and an interactive Stability & substitutions workspace with clickable lane/bucket cells, Model/Provider/Credential failure attribution tables, and an in-place `StabilityDetailDrawer` showing bounded redacted failure samples and management shortcuts.
- **Batched quota reads, cold-boot prefetch, and calm signal semantics.** Batched quota snapshot history, capacity cycles, and physical-usage streaming reads (`GetQuotaSnapshotHistoryBatch`, `LoadCapacityCyclesBatch`, `ReadQuotaTrendBatch`) and prefetched `/trends` quota queries on authenticated cold boot. Removed drag-brush and wheel-zoom traps from Trends charts, aligned stat tile value/footer slots with total error readouts, and reserved red failure hues strictly for genuine failure verdicts.

## Insights & Console Polish

- **Insights Model load profile default with Avg TPS.** Switched `KeyCompositionPanel` to open directly on **Model load profile** on both desktop and phone, replaced per-call input/output columns with **Avg TPS**, and added a compact mobile telemetry card grid with sort direction toggles and drawer drill-in.
- **Unified tinted `StatusLabel` chips & aligned `StatTiles`.** Standardized status indicators across Request Records, Request Sheet PNG exports, Quotas, OAuth credentials, Configuration, Plugins, Agent, and Playground onto a single tinted `StatusLabel` chip (`--radius-sm`) with WCAG AA contrast ink mixing (`--status-ink-share`) across all six palettes, and baseline-aligned `StatTiles` label pips.
- **Refreshed documentation screenshots.** Updated the English and Chinese README screenshots to reflect current Insights and console views.

## Configuration & OAuth

- **Claude OAuth `org:create_api_key` scope switch.** Exposed `oauth.providers.claude.oauth-include-create-api-key` under **Configuration → Providers** (Claude Behavior) and displayed the active Claude authorization scope in the Claude login drawer.
- **Custom CPA model catalog sources.** Exposed `models.catalog`, `models.codex-catalog`, and `models.devin-catalog` under **Configuration → Providers** so operators can point CPA at custom HTTP(S) URLs or absolute local JSON files, refreshing Model Square provenance automatically on save.

## Upgrade notes

- Back up `.env` and your SQLite database or volume before upgrading; refer to `docs/ops/sqlite-operations.md`.
- Database migration `071_usage_events_completed_index.sql` runs automatically at startup after creating an encrypted pre-migration backup (`*-before-migration-71.db.enc`). On large `usage_events` tables, building `idx_usage_events_instance_auth_completed` can add a few seconds to first startup.
- `oauth.providers.claude.oauth-include-create-api-key` requires CLIProxyAPI v8.0.78 or later; `models.catalog`, `models.codex-catalog`, and `models.devin-catalog` remain omitted unless configured, leaving older CPA v8 gateways unaffected.
- No new required environment variables or Compose changes are introduced in v0.4.8.
- Container images are available on Docker Hub as `wiziscool/oh-my-cpa:v0.4.8` and `wiziscool/oh-my-cpa:0.4.8`.
