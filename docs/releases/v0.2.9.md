# Oh My CPA v0.2.9

## Policy-approved automatic warmup

- **Start from the approved policy**: Codex and Claude automatic window warmup can make the first eligible attempt without a prior manual activation. Operators still explicitly select a model and confirm the policy; automation remains off by default.
- **Current readiness, separate activation history**: Credential details show the current window or billing pause reason. Activation observations describe whether activation has been observed for the selected model rather than imposing a manual prerequisite. Immediate warmup remains an optional confirmed action.
- **Durable model-specific safeguards**: An unsupported protocol response or unexpected tool response pauses automatic requests for that model. The pause survives a rate-limited manual recheck and restarts, independently of the latest receipt. Observed activation for that model clears the pause; another explicitly selected model is evaluated independently. Ordinary rate-limit backoff, paid-fallback protection and uncertain-outcome suppression remain in place.

## Stable responsive drawers

- Drawer widths adopt the viewport immediately instead of interpolating during a transition, keeping the 320px Warmup settings sheet within the screen.
- Normal drawer motion transitions only position; reduced-motion preference disables the wrapper transition. Existing motion tokens and geometry tolerances remain unchanged.

## Upgrade notes

- Back up the persistent SQLite database and preserve its master key before upgrading; follow `docs/ops/sqlite-operations.md`.
- This patch adds optional model-specific pause evidence to the existing warmup state JSON. It does not add a SQL migration beyond the v0.2.8 warmup tables; existing unsupported-response receipts are retained when rechecked.
- **Previously enabled policies become eligible for their first automatic attempt on the next eligible scheduler round**, without a manual activation prerequisite. Review the selected credential, model and policy before upgrading if this changes your intended behavior. Disabled policies remain disabled.
- Paid fallback must be affirmatively disabled. Enabled or unknown billing evidence still pauses consuming requests; warmup uses subscription quota, never redeems reset credits, and does not silently substitute a model.
- Hermetic regression checks use fake providers. They do not establish live activation compatibility for every real credential/model combination; activation is reported only after quota evidence confirms it.
- Compose continues to default to `latest`. After publication, pin this release with `wiziscool/oh-my-cpa:v0.2.9` or `wiziscool/oh-my-cpa:0.2.9`. Docker images and the eight native executable archives retain the existing publication workflow.
