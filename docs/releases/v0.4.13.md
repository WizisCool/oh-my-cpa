# Oh My CPA v0.4.13

Oh My CPA v0.4.13 raises management request-body limits to match domain ceilings with consistent HTTP `413` reporting, redraws the sign-in showcase with the live routing map, refines OAuth connect field spacing, and refreshes documentation screenshots.

## Management Request-Body Limits & 413 Handling

- **Request-body caps aligned with domain ceilings.** Raised `MaxBytesReader` limits across management endpoints: `2 MiB` for provider CRUD (`internal/api/management_provider_crud.go`), auth-file/OAuth rule mutations (`internal/api/management_auth_files.go`), and routing (`internal/api/management_routing.go`); `4 MiB` JSON-escaping headroom on `PUT /v1/management/config/source` while enforcing `CONFIG_YAML_LIMIT` (`2 MiB`) on decoded YAML (`internal/api/management_config.go`, `internal/cpa/management/client_config.go`); `1 MiB` for plugin configuration (`internal/api/management_plugins.go`); `64 KiB` for pricing models (`internal/api/management_pricing.go`); and `16 KiB` for client API keys and outbound proxy settings (`internal/api/management_client_keys.go`, `internal/api/management_outbound_proxy.go`).
- **Explicit HTTP `413 request_too_large` responses.** Updated `decodeManagementJSON`, ad-hoc body readers across management/auth/database/agent endpoints, and `internal/updater/server.go` to return HTTP `413` (`code: "request_too_large"`) instead of masking `*http.MaxBytesError` as `400`, added localized `request_too_large` and `cpa_request_too_large` error messages across all four locales (`zh`, `en`, `zh-Hant`, `ms`), and regenerated `docs/openapi/swagger.json` with `@Failure 413` annotations.

## Sign-In Showcase & OAuth Connect Polish

- **Live routing map sign-in showcase.** Rebuilt `SignInStage` using the dashboard routing map's stylesheet, shared `wire` tokens, and scripted `createPacketPlayer` packet animations while dropping the redundant showcase headline and body copy.
- **Consistent OAuth connect field spacing.** Wrapped the session-proxy field in `OAuthConnectPanel` with the shared `.field` 6px rhythm and removed `.field-label`'s duplicate bottom margin so every connect field aligns evenly.

## Documentation

- **Refreshed README screenshots.** Updated English and Chinese console screenshots under `docs/images/readme/`.

## Upgrade notes

- Back up `.env` and your SQLite database or volume before upgrading; refer to `docs/ops/sqlite-operations.md`.
- No database migrations, new required environment variables, or Compose changes are introduced in v0.4.13.
- Container images are available on Docker Hub as `wiziscool/oh-my-cpa:v0.4.13` and `wiziscool/oh-my-cpa:0.4.13`.
