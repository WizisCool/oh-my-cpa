# Oh My CPA v0.4.9

Oh My CPA v0.4.9 hardens mobile background-resume stability and session reconnection, adds inline quota recovery and live `management-quota` cache synchronization on Trends, unifies small chip geometry and icon alignment across the console, and refines System backup and update progress controls.

## Mobile Resilience & Session Continuity

- **Background-resume stability and lower mobile memory footprint.** Guarded SPA chunk reloads and `vite:preloadError` recovery with document visibility and a 5-second post-resume grace window, disabled speculative idle route prewarming on mobile/coarse-pointer/Save-Data/low-memory devices, deferred dynamic font chunk loading until visible, and capped mobile hot-route slots to keep one active view in memory while preserving Dashboard's selected API-key filter.
- **Unified SSE suspension and throttled update checks.** Added a shared `createPageActivityMonitor()` lifecycle across `usage`, `system`, and `state` SSE channels to suspend cleanly across `visibilitychange`, `pagehide`/`pageshow`, and `freeze`/`resume`, and throttled reconnect-driven update revalidation with a 60-second minimum age while keeping real `updates` events immediate.
- **Graceful cold-reload continuity and transient reconnect handling.** Added allowlisted, non-sensitive UI continuity metadata (auth shell hint, static console route scroll offset, and standalone PWA route with a 30-minute TTL, cleared immediately on sign-out or genuine `401`) and an 8-second timeout on `api.getSession()` so transient wake-up network errors show a reconnect prompt with automatic `online`/`visibilitychange` retry rather than flashing sign-in.

## Trends Quota Recovery & Cache Sync

- **Inline recovery actions for unreachable CPA and stale quota readings.** Separated CPA unreachability (`is_membership_unknown`) from stale or expired credential readings on the Trends Quota Burn panel, adding an inline **Retry** button for unreachable gateways and a **Refresh quota** action backed by the shared `refreshCredentialQuotas()` SSE flow with per-credential concurrency locking.
- **Cross-tab `management-quota` synchronization.** Published `management-quota` `state_sync` events from both manual quota refreshes (`POST /api/v1/management/quota/refresh` / `/batch`) and background auto-refresh rounds, and linked `QUERY_KEYS.trendsQuota` across quota, warmup, OAuth, auth-file, and configuration mutations.

## Console Polish & System Controls

- **Unified `20px` small chip geometry and icon alignment.** Standardized small chips, badges, count pills, `Combobox` multi-select chips, canvas request-sheet tags, and `StatusLabel` chips onto `20px` height (`7px` horizontal padding) with centered `12px`/`14px` icon caps and `1.25` line-height on ellipsized `StatusLabel` text to prevent descender and CJK clipping.
- **Lit running buttons and `StageProgress` for backups and updates.** Kept `aria-busy` loading buttons at full weight and color with a `progress` cursor while disabled buttons remain dimmed, introduced the shared `StageProgress` bar with spoken stage labels and step counts (`n/total`) across database backups and product updates, and placed verdict chips and actions inline on System version and backup cards.
- **Dashboard card cleanup & refreshed screenshots.** Removed the duplicate total summary from the Dashboard `ModelUsagePanel` header (already shown in the KPI row above) and updated English and Chinese README screenshots.

## Upgrade notes

- Back up `.env` and your SQLite database or volume before upgrading; refer to `docs/ops/sqlite-operations.md`.
- No database migrations, new required environment variables, or Compose changes are introduced in v0.4.9.
- Container images are available on Docker Hub as `wiziscool/oh-my-cpa:v0.4.9` and `wiziscool/oh-my-cpa:0.4.9`.
