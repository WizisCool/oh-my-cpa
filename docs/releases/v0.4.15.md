# Oh My CPA v0.4.15

Oh My CPA v0.4.15 adds a Codex reset-credit picker and confirmation dialog with earliest-expiring redemption, adds per-request diagnostic log export and inline raw log viewing, fixes Codex subscription billing-cycle slicing and rollover refreshes, exposes Vertex request-scoped error rules, improves Antigravity CLI attribution, hardens fast-gate verification stability, and refreshes documentation screenshots.

## Codex Reset-Credit Selection & Subscription Cycles

- **Earliest-expiring redemption & explicit credit picker.** Reads the credential's live credit bank before redemption (`internal/quota/service.go`), defaults to the earliest unexpired available credit (tie-breaking by grant time and ID, with undated credits last), and extends `POST /api/v1/management/quota/redeem-credit` (`quotaRedeemCreditRequest`, `QuotaRedeemCreditResponseDTO`, `docs/openapi/swagger.json`) with an optional `credit_id` recorded in audit logs. Fails closed with `409 reset_credit_not_available` (without substituting another credit), `409 reset_credit_unavailable`, or `502 reset_credit_bank_unreadable` when the requested credit or bank is unavailable. Renders Codex reset credits as read-only flat peer cards in `QuotaResetCards` and adds the shared `RedeemResetCreditDialog` (opened from both the drawer **Reset quota** button and the list/card **Use a reset** menu) with single-card keyboard/pointer selection, latched opening state across background quota refreshes, destructive confirmation, demo sandbox parity (`web/src/demo/sandbox.ts`), and translations across all four locales (`zh`, `en`, `zh-Hant`, `ms`).
- **Authoritative `billing_period` slicing & rollover refresh.** Parses and persists upstream `billing_period` (`weekly`, `monthly`, `quarterly`, `yearly`) on `QuotaPlan` (`quota_snapshots.plan_json`, without a schema migration) from Codex subscription responses (`internal/quota/codex.go`, `internal/quota/subscription_cycle.go`), slicing renewed multi-month tenures anchored at `ExpiresAtMS` with month-end anchor recovery and prorated first-cycle clipping while preserving `[StartsAtMS, ExpiresAtMS)` when `billing_period` is absent. Scopes the `QuotaCapacityDialog` subscription query key to the verified billing-period identity (`activeSubscriptionPeriodKey` / `quotaSubscriptionPeriodKey` across drawer, list, and card views) so an already-open dialog clears stale figures and fetches the new cycle immediately on rollover while retaining same-period cache reuse.

## Usage Diagnostics & Client Attribution

- **Per-request diagnostic log export & inline raw log viewer.** Adds single-record OMC diagnostic export (`web/src/components/usage/requestRecordLog.ts`) in `UsageEventDrawer` supporting localized `.log` text, structured `omc.request.log.v1` JSON downloads, and clipboard JSON copy with allowlisted fields, masked OAuth identities, and omitted key HMAC fingerprints. Extends `LogFileViewer` and `LogViewerTarget` (`kind: 'usageEvent'`) so operators can inspect and download CPA raw request logs inline in a single audited read, with status guidance and one-click `request_log` enablement when CPA request logging is off, across all four locales.
- **Antigravity CLI User-Agent attribution.** Updates `ClassifyClientAgent` (`internal/usage/client_agent.go`) to classify `google-genai-sdk/<ver>` requests carrying Google's internal dated Go runtime (`gl-go/go<major>.<minor>[.<patch>]-<YYYYMMDD>`) and numeric Piper changelist (`cl/<6+ digits>`) as `antigravity` (`ClientAgentAntigravity`, category `agent`) while preserving explicit agent precedence (such as `GeminiCLI`) and keeping public Go, Python, and Node SDK traffic under `google-genai-sdk`.

## Vertex Provider Policy

- **Request-scoped error rules for Vertex.** Enables `hasErrorRules` (`request-scoped-errors`) for `ConfigFamilyVertex` in `providerPolicyCapabilitiesFor` (`internal/api/management_provider_policy.go`) with explicit fail-closed capability enumeration for undeclared families, and sets `supportsErrorRules: true` for `vertex` in `PROVIDER_FAMILIES` (`web/src/types/providerFamilies.ts`) to reuse `ErrorRulesEditor`, submit-time validation, and v8 group inheritance/override semantics.

## Verification, CI & Documentation

- **Fast-gate `theme-boot` stability.** Eliminates redundant `web/src` walks, barrel imports, and full-tree TSX AST parsing in `web/tests/logic/theme-boot.test.ts` with a conservative JSX opening-tag pre-filter, caps `OMC_SHARED_CPU` Vitest workers in `web/vitest.config.ts`, and adds slow-case diagnostics (`>= 1500ms`) in `scripts/run-gates.mjs`.
- **Refreshed README screenshots.** Updates English and Chinese console screenshots under `docs/images/readme/`.

## Upgrade notes

- Back up `.env` and your SQLite database or volume before upgrading; refer to `docs/ops/sqlite-operations.md`.
- No database migrations, new required environment variables, or Compose changes are introduced in v0.4.15.
- Request-scoped error rules for Vertex API-key providers require CLIProxyAPI v8.1.4 or later.
- Container images are available on Docker Hub as `wiziscool/oh-my-cpa:v0.4.15` and `wiziscool/oh-my-cpa:0.4.15`.
