# Oh My CPA v0.4.16

Oh My CPA v0.4.16 improves Codex and Claude reset-credit reliability and expiry checking, redesigns the Agent authorization page and exposes structured MCP approval links, clarifies CSP and external-request boundaries, lazy-loads the demo sandbox out of production first paint, removes an unused frontend dependency, and refreshes documentation screenshots.

## Quota Reset Credits & Expiry Checks

- **Reliable Codex reset credits & Claude reset grants.** Hardens Codex credit-bank parsing (`internal/quota/codex.go`, `internal/quota/service.go`, `internal/cpa/management/client_auth_files.go`) to accept numeric Unix epoch timestamps (seconds or milliseconds) alongside ISO-8601 strings, prefer `snake_case` over `camelCase`, drop entries with unparseable supplied expiries, preserve explicit `available_count: 0`, derive `AvailableCount` from redeemable `credits[]` when omitted, decode raw JWT `id_token` account claims without sending login emails as `Chatgpt-Account-Id`, and surface sanitized `ResetCredits.Error` while keeping `RedeemCodexCredit` fail-closed. Hardens Claude reset grants (`internal/quota/claude.go`, `internal/quota/types.go`, `internal/quota/service.go`, `internal/api/quota_read_gate.go`, `internal/api/management_quota.go`, `docs/openapi/swagger.json`) by spacing supplementary `?cedar_ember=1&skip_spend=1` calls by 2s (`DefaultClaudeResetGrantsDelay`) after the primary usage read, treating empty-string `ends_at` as absent, preserving prior `ResetGrants` across failed or deferred reads with a 2-minute failure cooldown (`QUOTA_CLAUDE_RESET_GRANTS_FAILURE_COOLDOWN`), and exposing sanitized `reset_grants_error` codes (`rate_limited`, `auth_error`, `upstream_error`, `invalid_payload`). Updates OAuth List, Card, and Detail Drawer views (`CredentialParts.tsx`, `CredentialCards.tsx`, `CredentialList.tsx`, `CredentialQuotaBody.tsx`, `QuotaResetCards.tsx`, `quotaFormat.ts`, and all four locales `zh`, `en`, `zh-Hant`, `ms`) to show clickable reset-count tags with structured `TipCard` expiry lists, compact flat inline expiry rows (soonest-expiring first) on cards, explicit `0` meta counts when observed without error, and warning indicators when supplementary reads fail.
- **Live credit-expiry recheck in open redemption dialogs.** Adds `nextCodexResetCreditExpiryDelayMS` (`web/src/pages/quota/quotaFormat.ts`) and replaces the frozen `redeemOpenedAtMS` timestamp in `CredentialMenu` (`web/src/pages/oauthManagement/CredentialParts.tsx`) with a live eligibility clock in `RedeemResetCreditDialog` that runs only while open (pausing while hidden or submitting and resyncing on `visibilitychange`). Rechecks eligibility on option selection and immediately before dispatch, disabling confirmation with an unavailability warning rather than dispatching an expired credit or auto-substituting another one.

## Agent Authorization & MCP Approval Links

- **Redesigned authorization page (`/authorize/:id`).** Aligns `AuthorizePage` (`web/src/pages/agent/AuthorizePage.tsx`, `AuthorizePage.module.css`) and its loading skeletons (`ShellLoading.tsx`, `PageLoading.tsx`) with the sign-in layout: wordmark header, left-aligned title and introduction, and a single `--shadow-edge` request card showing the capability, identifier, and permission tag. Renders top-level scalar preview fields as label/value rows (omitting server-only `hmac:` revision fingerprints) with nested parts as JSON, retains the preview after a decision alongside a `StatusLabel` outcome with failure reasons and codes, distinguishes `resource_conflict` from conversation conflicts, and leads `uncertain` outcomes with the warning that the change may have been applied.
- **Structured MCP `approval_url` delivery.** Includes `approval_url` in `structuredContent` (and declared output schemas, including `omc_operation_status`) for pending MCP tool calls (`internal/mcpbridge/bridge.go`, `internal/api/agent_mcp.go`, `internal/capability/registry.go`) so MCP clients such as Claude Code and Codex surface a clickable approval link alongside the text fallback. Streamable HTTP prefers `OMCPA_PUBLIC_URL` when configured while stdio continues using `OMCPA_SERVER_URL`; updates `docs/features/agent.md`, `docs/zh/features/agent.md`, and Connect guide copy across all four locales.

## Security Boundaries, Performance & Cleanup

- **Aligned CSP Report-Only boundary & offline OpenUI export sanitization.** Clarifies `Content-Security-Policy-Report-Only` in `internal/api/handler.go`, `docs/dev/architecture.md`, `docs/agent-capabilities.md`, and `docs/zh/agent-capabilities.md` as a diagnostic header on console and API routes while keeping enforced CSP and sandbox boundaries intact across frame shells, uploaded user assets, `present_html` iframes, offline exported conversation HTML, and Markdown links. Removes the asynchronous `MutationObserver` JS fence (`noRemoteAssets.ts`), isolates pure offline HTML export sanitization in `web/src/agent/openui/exportMarkup.ts`, refreshes `internal/agent/openui/openui.json` and `PROMPT_VERSION`, and extends Go and browser acceptance checks for report-only CSP, `Referrer-Policy: no-referrer`, and `frame-src 'self' blob:`.
- **Lazy-loaded demo sandbox & dependency cleanup.** Replaces static `web/src/demo/sandbox.ts` imports in `web/src/components/common/HeaderNav.tsx` with an on-demand dynamic import invoked only in demo mode, removing 6 chunks (`-96.7 KiB` raw / `-27.3 KiB` gzip) from `AppLayout`'s production first-paint graph, and enforces the `AppLayout -> sandbox.ts` boundary in `scripts/bundle-report.mjs`. Removes the unused `simple-icons` devDependency from `web/package.json` and `pnpm-lock.yaml`.

## Documentation

- **External requests inventory & optional-CDN wording.** Publishes a complete operator inventory of built-in external HTTP(S) requests made by the OMC server, browser SPA, and updater sidecar (and separates CPA-delegated and operator-configured endpoints) in `docs/operations.md` and `docs/zh/operations.md`, and aligns stale offline and zero-CDN wording in `docs/dev/architecture.md` and code comments with the optional-CDN contract.
- **Refreshed README screenshots.** Updates English and Chinese console screenshots under `docs/images/readme/`.

## Upgrade notes

- Back up `.env` and your SQLite database or volume before upgrading; refer to `docs/ops/sqlite-operations.md`.
- No database migrations, new required environment variables, or Compose changes are introduced in v0.4.16.
- Operators exposing the Streamable HTTP MCP endpoint behind a reverse proxy or container network can set `OMCPA_PUBLIC_URL` so MCP `approval_url` links resolve to a browser-reachable address.
- Container images are available on Docker Hub as `wiziscool/oh-my-cpa:v0.4.16` and `wiziscool/oh-my-cpa:0.4.16`.
