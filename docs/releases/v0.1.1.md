# Oh My CPA v0.1.1

## Quota window capacity

- The OAuth workspace now shows recorded window usage and estimated full-window
  token/cost capacity for Codex and Claude global windows, Claude model-scoped
  windows, and reviewed Antigravity model groups.
- Estimates use request-time locked costs and align recorded usage with the
  quota observation. Low usage, uncertain boundaries, stale observations,
  unresolved model scopes and retained reset/history gaps refuse an estimate.
  Dollar estimates also require sufficient priced-request coverage.
- A window with insufficient current usage can show a labelled estimate from the
  immediately preceding scheduled cycle when that cycle passes retained-history
  validation. This is a historical capacity estimate, not a usage forecast.
- The console and Agent quota capabilities share the same calculation. Compact
  rows keep long full-digit token estimates readable within their own window.

## Served-model observability

- Request records and details retain the model reported by the upstream response
  and identify substitutions relative to the requested model and its alias.
- Request search and the served-model filter distinguish substituted and matched
  records. An absent upstream report remains unknown rather than implying a match.

## Installation and release reliability

- Installation guides distinguish a fresh stack from an existing CPA deployment
  and include adding OMC as a service to CPA's own Compose file.
- Release verification provisions and launch-probes Chromium before running the
  full acceptance gates.
- Demo fixtures include scoped quota estimates, previous-cycle references and
  served-model substitutions. Quota seed failures retain their original error
  with operation and credential context.

## Upgrade notes

- Existing installations apply `migrations/034_usage_events_response_model.sql`
  through the normal startup migration and backup gates. The migration adds
  served-model metadata; records collected before it retain an unknown served
  model and are not backfilled.
- Preserve the persistent data directory and its master key, and follow
  `docs/ops/sqlite-operations.md` for backup and recovery. Do not rewind migration
  history when recovering an installation.
- Compose continues to default to `latest`. For a version-pinned deployment, use
  `wiziscool/oh-my-cpa:v0.1.1` or `wiziscool/oh-my-cpa:0.1.1` after publication.
  Both `linux/amd64` and `linux/arm64` are distributed through Docker Hub.
