# Oh My CPA v0.3.8

This release keeps failed quota refreshes visible, adds a managed Oh My CPA
plugin registry to the plugin store, and guides OpenCode endpoints to attach
the session header they need.

## Managed Oh My CPA plugin registry

- The plugin store includes Oh My CPA's published registry as a managed source,
  enabled by default. Operators no longer need to add its address manually.
- Entries from that registry are marked, named `Oh My CPA`, and listed before
  other registries while preserving each registry's own order. Installing one
  still requires confirming the plugin id.
- The source is reconciled during store reads and configuration saves. The
  managed address never becomes an editable duplicate, and the Oh My CPA
  Settings switch is the supported way to disable it.
- A repair that cannot be backed up or audited makes the operation fail instead
  of writing an unverified configuration.

## OpenCode session guidance

- When a provider's Base URL uses the exact `opencode.ai` host, the editor shows
  an inline notice beside the address on every lane path.
- One click adds `x-opencode-session: $CPA-SESSION-ID` to the draft and reveals
  Custom Headers. CPA expands the value for the request; Save persists it.
- Duplicate or conflicting header rows are resolved safely: a blank duplicate
  cannot overwrite a configured id, and two different ids require operator
  review instead of an automatic choice.

## Quota refresh status

- A failed refresh now remains visible after its error toast closes. The row
  names the latest attempt and its reason, keeps the last usable reading, and
  offers a refresh action for that credential.
- Authentication failures mark the credential for reauthorization. Other
  failures show a stale reading when one exists, or a failed-read state when no
  usable reading has ever been stored.
- Healthy or warning readings that pass their own announced reset boundary are
  reported as stale instead of healthy. The summary separates stale snapshots
  from current healthy readings.
- Attempt timestamps use the quota clock and are captured before the read
  starts, so overlapping reads retain the attempt that began last.

## Upgrade notes

- Back up `.env` and the data directory or volume before upgrading; follow
  `docs/ops/sqlite-operations.md`. Migration 044 adds
  `quota_refresh_attempts`; the schema advances to
  `044_quota_refresh_attempts.sql`.
- The managed plugin source is added to CPA's `plugins.store-sources` when the
  switch is on. Existing revision guards, configuration backups and audit
  requirements remain in effect. Turn the source off from Oh My CPA Settings
  when it is not wanted.
- OMC's general CPA v8.0.0 Management API baseline is unchanged. The plugin
  source and quota controls do not change request routing.
- Compose continues to default to `latest`. After publication, pin this release
  with `wiziscool/oh-my-cpa:v0.3.8` or `wiziscool/oh-my-cpa:0.3.8`.
