# Oh My CPA v0.4.12

Oh My CPA v0.4.12 adds built-in GitHub Copilot device-code OAuth sign-in, customizable column visibility and ordering for the `/usage/events` request table, and refreshed documentation screenshots.

## GitHub Copilot Device Sign-In Flow

- **Built-in Copilot OAuth provider.** Registered `copilot` (`GitHub Copilot`) as an RFC 8628 device-code flow (`OAuthFlowDevice`) in `internal/cpa/management/oauth_providers.go`, projecting into `GET /api/v1/management/oauth/providers`, forwarding `provider=copilot` without `is_webui=true`, and exposing `copilot` through `oauth_providers` and `oauth_connect` capabilities.
- **Console sign-in, recovery, and plugin deduplication.** Added the Copilot sign-in card to `/oauth`, enabled targeted credential re-authentication via `/oauth?provider=copilot` and credential recovery actions, reserved `copilot` in `BUILTIN_OAUTH_IDS` so plugin cards do not duplicate the built-in entry, wrapped long device codes cleanly on narrow viewports, and updated all four locale catalogs and demo fixtures.

## Customizable Request-Table Columns

- **Column visibility and order popover.** Added a **Columns** (`RequestColumnsPopover`) menu in the `/usage/events` toolbar allowing operators to show, hide, and drag-or-keyboard reorder columns (`RowReorder`), view auto-folded status badges, and independently run **Show all**, **Reset order**, and **Reset widths** while keeping at least one column visible.
- **Backward-compatible preferences and glide motion.** Extended `usage_events_columns` with optional `hidden` and `order` arrays while preserving existing pixel width overrides, composed user-hidden columns with width-driven responsive folding and dynamic seam spacing in desktop grid mode (`> 920px`, leaving mobile stacked cards untouched), added single-move horizontal FLIP glide animations honoring `isMotionReduced()`, and prevented transient `['preferences']` read failures from marking unloaded optimistic writes as server-loaded.

## Documentation

- **Refreshed README screenshots.** Updated English and Chinese console screenshots under `docs/images/readme/`.

## Upgrade notes

- Back up `.env` and your SQLite database or volume before upgrading; refer to `docs/ops/sqlite-operations.md`.
- No database migrations, new required environment variables, or Compose changes are introduced in v0.4.12. Existing `usage_events_columns` width preferences remain compatible.
- Built-in GitHub Copilot device-code sign-in requires CLIProxyAPI v8.1.1 or later with `copilot` support on `/v8/management/oauth/auth-url`.
- Container images are available on Docker Hub as `wiziscool/oh-my-cpa:v0.4.12` and `wiziscool/oh-my-cpa:0.4.12`.
