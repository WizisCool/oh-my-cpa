# Oh My CPA v0.4.6

Oh My CPA v0.4.6 moves Model Square model specifications and reasoning metadata onto the locally synced OpenRouter cache, adds per-model icon selection, exposes CPA's `requests.payload.replace` user text replacement rules in Configuration, plots per-bucket cache rates on the Dashboard Cache rate tile, redesigns console loading skeletons around a unified route registry, and fixes panel and form-control alignment issues.

## Model Square & OpenRouter model metadata

- **OpenRouter-backed specifications and reasoning metadata.** Migration `066_openrouter_model_metadata.sql` extends `pricing_upstream_catalog` with model descriptions, `max_completion_tokens`, input/output modalities, supported parameters, structured reasoning metadata, `knowledge_cutoff`, and sanitized `hugging_face_id` values. Model Square and workspace context readouts read these specifications from the local memory/SQLite cache (`MatchMetadata`) with zero outbound requests per view, keeping strict billing rules (`MatchModel`) isolated while retiring the bundled static `models.dev` snapshot (`internal/modelcatalog`), `pnpm models:sync`, and the 30-day release snapshot-age gate.
- **Reordered Model Square drawer, shared `<EffortTag>`, and unified connections & pricing.** Placed matched model specifications at the top of the Model Square detail drawer, replaced plain modality names with localized icon marks and tooltips across all four locales, extracted the shared `<EffortTag>` badge used across Model Square and request records, and combined connections and per-route pricing with inline edit actions.
- **Per-model icon selection and Model Square hover polish.** Added the `model_icons` preference and `IdentityDirectoryResponse.model_icons` with live state sync, allowing operators to assign or reset icons per model using the shared `IconPickerModal`, `IconTileButton`, and custom icon library (cleaning up `custom:<id>` references across both `provider_icons` and `model_icons`). Refined card hover lift, copy-name wash, chevron reveal scoping, and outer keyboard focus rings on `/model-square`.

## Configuration & Dashboard

- **Visual editor for `requests.payload.replace`.** Exposed CLIProxyAPI v8.0.75 literal user-text replacement rules under **Configuration → Payload** (`Replacement Rules`), supporting ordered rules and replacement entries (`RowReorder` and step controls), `all` or integer `positions` targeting, phrase deletion (`""`) and whitespace-only literal sources, advanced protocol/header/JSON condition editing, verbatim preservation of unsupported YAML roles or malformed entries, and synchronous draft validation and pending-input flushing before save or navigation.
- **Per-bucket cache rate sparkline on Dashboard.** Added `cache_rate` (`*float64`, `omitempty`) to `dashboardSeriesPoint` and updated `DashboardTrendChart` and `buildMonotoneSparkline` so the Dashboard **Cache rate** tile plots each bucket's computed cache hit rate on a 0–100% scale rather than raw cache-read token volume, rendering buckets without prompt tokens as disjoint segments and isolated markers with `—` readouts instead of bridging or zeroing across idle gaps.

## Console skeletons, alignment & documentation

- **Redesigned console skeletons and single-source route loading registry.** Consolidated shell and lazy-route skeletons onto `ROUTE_DESCRIPTORS.loadingBody` (`routePreload.ts`) and `PAGE_SKELETON_REGISTRY` (`PageLoading.tsx`) with Quiet Panel `oklab` ink-wash placeholders, compositor-only breathing (`data-reduced-motion` and `forced-colors` fallbacks), and `LoadingRegion` 240ms handover phase synchronization across shell boot, chunk loading, and initial data reads.
- **Dashboard, empty-state, and form-control alignment fixes.** Omitted empty model-trend legend margins and standardized compact `EmptyState` rendering across Dashboard panels, centered single-empty-state panel bodies, aligned Configuration switch labels with sibling controls, updated retired `input-wrapper` selectors to `[data-slot="input"]` (restoring the `280px` tier-threshold max width in Model Pricing), and refreshed the English and Chinese README screenshots.

## Upgrade notes

- Back up `.env` and your SQLite database or volume before upgrading; refer to `docs/ops/sqlite-operations.md`.
- Database migration `066_openrouter_model_metadata.sql` adds model metadata columns to `pricing_upstream_catalog`. It is forward-only and runs automatically at startup after an encrypted pre-migration backup.
- `pricing_get` and price-detail responses no longer include `reference_prices` (and Model Square responses no longer include `metadata_updated_at`), as OpenRouter specifications replace the removed bundled `models.dev` snapshot; until an installation's first OpenRouter catalog sync completes, model specifications remain absent rather than failing.
- No new required environment variables or Compose changes are introduced in v0.4.6.
- Container images are available on Docker Hub as `wiziscool/oh-my-cpa:v0.4.6` and `wiziscool/oh-my-cpa:0.4.6`.
