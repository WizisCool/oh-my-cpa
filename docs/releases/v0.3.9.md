# Oh My CPA v0.3.9

This release aligns usage billing with CPA's final outbound service tier,
keeps provider credentials and quota cooldowns from getting stuck, and makes
the console installable as a web app. It also repairs the managed Oh My CPA
plugin registry and adds the OMC edition of Codex Candy Eval.

## Installable console

- The console now serves a mount-aware web app manifest and local app icons.
  Chrome and Edge on desktop and Chrome on Android can install it from the
  served page; Safari on iOS and iPadOS uses **Add to Home Screen**.
- No service worker was added. Sessions, HTTP caching and deep links keep
  their existing boundaries, and the manifest resolves under a configured
  base path.

## Billing and usage accuracy

- Codex billing and Fast indicators resolve from the request evidence OMC
  records, and from CPA's optional final outbound `effective_service_tier`
  when it is reported. An explicit outbound `auto` selects no service-tier
  price; non-Codex providers keep their response-first policy.
- Records without outbound evidence keep the previous fallback, so older CPA
  versions, mixed-format queues and CPA downgrades remain compatible.
- Request details show request, outbound and response tier evidence
  separately. Filters, facets, pricing labels and exports use the resolved
  evidence; masked exports omit the outbound field.
- Historical amounts and their explanations are unchanged. New costs lock
  their tier and source snapshot when the request is recorded.
- The request list's cache cell shows only the hit rate. The exact cached
  token count remains available in the cell's tooltip.

## Providers and credentials

- Saving a config-family provider keeps every submitted API key as its own
  row in one backed-up, revision-guarded write. Each key keeps its proxy and
  weight, and shared provider settings, names, websites and icons reach every
  saved row.
- Refusals carry stable codes that the editor translates; the English message
  remains the fallback for logs and agent clients.

## Quota

- Reading Claude Code reset grants now sends the `x-app: cli` header and
  Claude CLI user agent those grants require, so used and remaining grants are
  reported instead of a generic failure.
- Plugin quota periods recognize common aliases, and monthly plugin quotas are
  named as monthly without treating a calendar month as a fixed 30-day
  duration. Fallback bucket identities stay attached to their original
  windows when display ordering changes.
- A credential whose quota comes back no longer waits for an operator to
  click Clear Cooldown. A fresh usable read with room left in every published
  window releases the CPA cooldown, as does a background round where every
  stored recovery and retry time has passed. Each release is audited as
  `quota.clear_cooldown.automatic` with the reason `capacity_restored` or
  `recovery_time_passed`.
- A window with no stated remainder keeps its cooldown, and a newer cooldown
  still in force keeps the credential blocked.

## Plugins

- The managed Oh My CPA registry now requires full
  `https://github.com/{owner}/{repo}` repository addresses and checks release
  version and install metadata before publication. A single malformed entry
  can no longer make CPA reject the whole registry.
- The managed source appears as one fixed row with the official-source glyph,
  its name and a link to the Oh My CPA Settings switch.
- The registry includes the independently identified OMC edition of Codex
  Candy Eval. Installing it still requires the usual third-party
  confirmation.

## Build and security

- Build and native-release toolchains move to Go 1.27.3 and Node.js 22.23.4.
  The Go module minimum is now 1.26, required by the upgraded `x/net`.
- `golang.org/x/net` moves to v0.60.0, `go-chi/chi/v5` to v5.3.0,
  `react-router-dom` to 7.18.4 and Vite to 6.4.4.

## Upgrade notes

- Back up `.env` and the data directory or volume before upgrading; follow
  `docs/ops/sqlite-operations.md`.
- Two forward-only migrations run: 045 adds the immutable service-tier
  snapshot columns, and 046 rebuilds `usage_events` to add the outbound tier
  while preserving rows, amounts, indexes, triggers, foreign keys and the
  request-id sequence. The schema advances to
  `046_usage_effective_service_tier.sql`.
- CPA's outbound service tier is optional and is reported by CPA v8.0.39 and
  later. When it is absent, pricing keeps the existing fallback rather than
  assuming a default outbound lane.
- Building from source now requires Go 1.26 or newer; the release toolchain
  pins Go 1.27.3 and Node.js 22.23.4.
- Compose continues to default to `latest`. After publication, pin this
  release with `wiziscool/oh-my-cpa:v0.3.9` or
  `wiziscool/oh-my-cpa:0.3.9`.
- Workflows, routing, credentials and the CPA Management API baseline are
  unchanged.
