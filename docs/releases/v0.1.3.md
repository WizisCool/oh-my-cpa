# Oh My CPA v0.1.3

## Native executables

- Releases now include executables for macOS, Windows, Linux and FreeBSD, each
  on amd64 and arm64. The embedded console runs without a frontend toolchain or
  Docker; CPA remains a separate required service.
- Archives include installation and operations guides, an environment template
  and the license. `checksums.txt` covers all eight archives and the Compose/CPA
  installation attachments. Darwin and Windows executables are not code-signed
  or notarized.
- Native packages and Docker images pass their respective smoke checks before
  the GitHub Release is published. Docker Hub continues to distribute
  `linux/amd64` and `linux/arm64` images.

## Request selection, export and filtering

- Select requests and export a palette-matched PNG or structured JSON. PNG
  export includes the newest 100 selected requests; JSON includes every selected
  request with the `omc.requests.v1` format identifier.
- OAuth account names and keys are redacted by default. Request IDs and whole
  columns can also be redacted; redacted JSON fields are omitted.
- Pattern filters match a supported field using an RE2 expression, validated
  on both the console and server. Agent/MCP request reads expose the same search
  and pattern filters.
- Request scrolling does less work, filter options share their provider/model
  marks, and non-streaming responses have an explicit marker.

## Billing time zones and agent pricing tools

- Time-of-day pricing tiers accept their own IANA billing time zone, including
  daylight-saving rules. The editor preserves the vendor's stated hours and
  shows their relationship to the console time zone.
- Existing tiers without a billing time zone remain UTC windows. Historical
  request prices and locked pricing versions are unchanged.
- Agent/MCP tools add pricing overview, per-model detail, catalog search,
  hypothetical quotes and recorded-request cost breakdowns. Proposed prices can
  be quoted before requesting approval; unresolved linked or automatic prices
  are refused during preparation.

## Provider, credential, quota and log management

- Provider controls add scoped cooldown overrides, retry counts, ordered error
  rules and supported request-behavior switches. Advanced model options follow
  their provider family, and credentials can have local model aliases.
- OAuth management supports individual and bounded batch token refresh, Kimi
  international sign-in and account-specific usage, and audited Vertex
  service-account file import. The agent's individual credential-refresh
  capability requires approval; Vertex key-file import stays in the console.
- Quota details show Codex prepaid credit standing, Meta Muse usage and weekly
  windows with explicit subscription state, and live xAI/Antigravity plan labels.
  Supplemental plan failures preserve independent quota observations.
- Meta Muse quota refresh uses a fixed server-side DCA exchange that can mint an
  upstream key. The exchange is audited before credential access; returned keys
  are discarded and are not written back to CPA.
- Gateway logs add counted method/path filters, persistent wrapping and
  fullscreen viewing in a compact toolbar.

## Console fixes and dependency security

- Codex request-behavior settings survive configuration saves and readback.
- OAuth cooldown feedback retains unexpected reasons and full diagnostics.
  Newly added provider model rows stay collapsed until explicitly opened.
- Native Select popups regain wheel scrolling, dashboard tooltips share aligned
  compact rows, and Model Square cards use the surface layer.
- Workspace-wide dependency overrides pin patched KaTeX, sharp and source-map-js
  versions for the three advisories documented in `SECURITY.md`.

## Upgrade notes

- Back up the persistent SQLite database and preserve its master key before
  upgrading; follow `docs/ops/sqlite-operations.md`. This release adds no database
  migration beyond v0.1.2 and does not change its retention defaults.
- For native installation, choose the archive for the host OS and architecture,
  verify its SHA-256 checksum, and configure the environment using the included
  template. HTTPS still requires the host's certificate roots.
- Compose continues to default to `latest`. To pin this release after publication,
  use `wiziscool/oh-my-cpa:v0.1.3` or `wiziscool/oh-my-cpa:0.1.3`.
