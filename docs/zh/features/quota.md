# 配额与预热

## 配额刷新与冷却

后端以固定受控端点刷新各提供商配额，并在所有窗口均恢复可用且冷却到期后自动清除 CPA 冷却；局部模型受限（如单模型限流）不会错误地让整个凭据显示不可用。

## 窗口预热

支持按配额窗口重置、每日定时或固定小时周期自动调度极轻量的激活探测（默认自动挑选价目表中价格大于 0 的最便宜模型，避免白跑免费模型无法激活付费窗口或浪费昂贵模型）；支持拖拽排序，且所有任务在发送请求前会先落盘写入执行记录（后续按任务更新并裁剪历史，删除任务时同步清理关联记录）并严格防范重发风险。

完整的调度、安全与记录规则见[英文版](../../features/quota.md)。
