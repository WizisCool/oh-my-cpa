# Storage service marks

Published product marks for the cloud services a backup can be sent to, so a location is
recognised by its logo before its name is read.

- `onedrive.svg`, `drive.svg`, `s3.svg` — the SVG Logos collection (CC0),
  `@iconify-json/logos`.
- Anything added from Simple Icons is CC0 as well.

These are product identity marks, not artwork of this project: keep them unmodified, and replace
one only with the service's current published mark. The images are bundled through
`../storageMarks.ts`, so they are inlined into the SPA and need no network access.
